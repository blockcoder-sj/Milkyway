## 직접 코드·보안 검토

매출 좌표는 발행인/CIK의 정확한 축 조합만 허용하고 추가·중복 축은 거절한다.
DTI 판매/Atlas 임대의 과거 캐시 구분을 정규화하되 원문 값은 바꾸지 않는다.
검토한 문서/기간의 내부거래 조정만 사용하고 다른 기간은 비중을 제외한다.
Atlas 중복 제거는 정확한 문서·기간·매출 지표의 shortfall에만 적용한다.

Range의 옛 ProFrac 북마크를 수동 확인한 ACDC 발행인과 연결한다. 이름만으로
합치지 않는다. FLOC 오조합 거절, 옛 북마크 redirect와 외래키/관계 보존을
검증했다. 이전 registry-only 캐시도 ACDC·정식 이름으로 정규화하며 상이한
티커는 병합 전에 거절한다. 미매핑 비상장 ID에는 상장 티커를 부여하지 않는다.
public 재무 캐시를 private seed로 덮지 않는다. 화면 설명은 허용
출처와 HTML escape를 거쳐 하단 출처 번호로 연결한다.

새 의존성·외부 수집 경로·AI/주문/자격증명 경로·DB 마이그레이션이 없다.
CodeRabbit을 사용하지 않았다. 변경 범위 직접 검토이며 전체 Codex Security
Scan 또는 공용 OCI/KMS 게이트 통과가 아니다.

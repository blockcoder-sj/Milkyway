# 미국 전체 자동 선별과 7일 페이퍼 운용

2026-11-05, 개인 PC 실행 기준. 전체 분석을 마친 뒤 새 계좌를 시작했다.
기존 10개 전략·2개 종료 계좌와 연결 키를 보존했다. 실제 증권사 주문은 전송하지 않는다.

## 변경과 이유

이전 제한은 전략의 고정 티커 필수 입력, AI 프롬프트, 개인 실행기의 20종목 제한에서
나왔다. 토스의 현재가 요청당 200종목 제한은 전체 분석 대상 수의 제한이 아니다.
전략에 `universe=us_market`을 추가하고 티커 목록을 비워 전체 시장을 자동 수집한다.
일반 미국 주식 요청에는 AI가 임의 예시 티커를 요구하지 않도록 바꿨다.

NYSE·NASDAQ·AMEX·US_ETC의 토스 거래 가능 보통주·ADR·REIT를 수집한다.
ETF·우선주·워런트는 제외한다. 이번 목록은 5,915개이고 모두 처리했다.
최소 가격 5달러·60거래일 이력·일평균 거래량 20만주 조건과 점수를 계산했다.
2,730개가 조건을 통과했다. 일봉 검증 불가 1개는 사유와 함께 제외했다.
나머지 제외에는 이력·가격·유동성·최신 완료 세션 조건 미달이 포함된다.

전용 `universe-data` 프로세스가 분석한다. 시세·체결 프로세스는 선정·보유 종목만
감시한다. 토스 동시 감시는 200개, KIS는 20개다. 전체 시장 수집에는 토스 연결이
필요하다. 새 미국 날짜·완료 세션·키 버전·필요 이력 변경을 확인하며 체크포인트를
이어 간다. 네트워크·요청 한도 오류는 재시도하고 미완료 분석으로 새 매수하지 않는다.

미완료 당일 일봉은 신호에서 제외한다. 공식 NYSE 거래일에 맞춰 거래정지·누락을
검사한다. 키 교체 중 수신한 자료는 현재 버전에 게시하지 않는다. 로컬 워커는
비공개 토큰 캐시와 파일 잠금을 공유해 OAuth 재발급 충돌을 막는다.

## 이번 운용

새 전략은 `미국 전체 Momentum LowVol Top3`다. 원래 전략의 모멘텀 60일 60%와
저변동성 20일 40%, 보유 3개, 투자 60%, 종목당 상한 25%, 7달력일 리밸런싱,
손절 5%, 편도 비용 0.1%, 동일비중 재조정을 그대로 유지했다.

운용 기간은 한국시간 **11월 5일 02:07:44부터 11월 12일 02:07:44까지**다.
ARX·PRTH·LFCR의 첫 가상 매수 3건을 02:07:56에 기록했다. 가상자금은 10만달러이며
투자 후 현금은 4만달러다. 종료 시 추가 체결을 중지하고 잔고·기록을 보존한다.
종료 시 보유 종목을 강제 청산하거나 공식 종가 체결을 만들어 내지 않는다.

기간은 DB에 저장한다. 재시작 후 같은 계좌를 이어가며 추가 초기 매수가 발생하지
않음을 확인했다. PC·Docker·네트워크가 켜져 있어야 계속 운용한다. 종료 중 지나간
시장 거래를 소급 체결하지 않는다. 프로세스 교체 직후에는 이전 실행 잠금이 풀릴
때까지 약 3분의 확인 대기가 발생할 수 있다.

## 화면과 삭제

계좌·전략에 삭제 버튼과 확인창을 추가했다. 계좌 삭제는 해당 잔고·체결·자산 기록을
삭제한다. 전략 삭제는 연결 계좌를 먼저 삭제해야 가능하며 실행 중인 백테스트가
있으면 거부한다. 인증·CSRF·소유권을 검사한다. 사용자의 기존 항목은 삭제하지 않았다.
직접 규칙 입력 폼은 제거했고 AI 연구 대화와 저장 버전 조정은 유지했다.
새 계좌를 만들면 운용 상태의 선택 계좌도 전환한다.

상태는 실행 여부·최신 가격 수·최근 판단·최근 체결·종료 시각을 표시한다.
일부 종목의 마지막 거래 시각이 오래된 경우 인터넷 오류와 구분해 갱신 대기로
표시한다. 새 가격이 오면 자동으로 이어 간다. Chrome 928px 창에서 전체 분석 완료,
정상 운용, 3/3 최신 시세, 새 계좌의 종료 시각과 삭제 버튼을 확인했다.

## 검증과 한계

- 전체 격리 검사 435개 중 425개 통과, Node가 없는 환경의 화면 검사 10개 건너뜀.
  호스트 화면 검사 12개·연구 UI 2개·시작 실행기 13개·토큰 캐시 3개 통과.
  이후 상태 문구 수정의 관련 실행 검사 12개도 통과했다.
- 실제 수집 자료를 사용하는 읽기 전용 전체 시장 백테스트가 16.154초에 완료됐다.
  최대 RSS는 약 481MiB이고 17건의 탐색용 체결을 계산했다. 일주일 실운용 검증은 아니다.
- 전체 일봉은 별도 불변 세대에 저장하고 기존 선택 종목 자료를 덮어쓰지 않는다.
  백테스트 기간·준비 이력 부족은 오류로 안내한다. 현재 거래 종목을 과거에 소급하므로
  생존편향이 있으며 무편향 PIT 성과로 표시하지 않는다.
- 앱·체결·자료·백테스트 등 6개 프로세스를 새 이미지로 교체했다. 시장 상세·백업
  프로세스와 모든 기존 볼륨 마운트는 보존했다. 수집용 임시 컨테이너는 증거 저장 후
  제거했다. 시작 실행기는 8개 서비스를 지원하며 PID 54932로 터미널과 분리 실행 중이다.
- 기존 계좌 2개의 잔고·포지션·체결·평가·기간 자료 SHA가 전후 일치했다. 기존 전략,
  증권사 연결, 백테스트도 보존됐다. 소스 직접 검토에서 소유권·삭제 종속성·입력 범위·
  시세 격리·재시도·키 버전·개인 파일 권한을 확인했다. 전체 보안 스캔은 수행하지 않았다.
- 최종 이미지 `55c6f9dbdd5f`의 앱 소스 82개 SHA가 작업 소스와 일치했다.
  live/startup/ready HTTP 200과 새 프로세스의 시세 수신을 확인했다.

증거는 Git에서 제외한 `runtime/verification-20261105/`에 보관한다. 토스 공식 명세,
수집 진행 기록, 격리 검사, 백테스트, 전후 원장·마운트, Chrome 화면을 포함한다.
실제 AI 호출·실주문·공개 배포·CodeRabbit·하위 agent는 사용하지 않았다.

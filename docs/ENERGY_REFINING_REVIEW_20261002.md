# Energy 정유사 조사 확장 · 2026-10-02

**중간 마일스톤이다. Energy 섹터나 정유 업종 전체 완료가 아니다.**

## 실제 추가한 자료

- Marathon Petroleum(MPC), Phillips 66(PSX), HF Sinclair(DINO)의 FY2025 사업·매출,
  정유/재생연료 설비, 제품 용도, 원료·물류·고객 경로, 2026년 2분기 변화.
- 각 기업 핵심 카드 8개, 제품·판매 경로 4~7개, 운영·경쟁 요인 4개.
  단순 영문 발췌 대신 한국어로 작성하고 각 사실에 문서를 연결했다.
- 대두 가공→재생 디젤, 기유 공급→윤활유 유통, 정유→물류→항공 고객 등의
  실제 계약 관계. MPC의 ADM/Green Bison/Neste/Martinez/7-Eleven,
  PSX의 Chevron/CPChem/Linde/United/DHL,
  DINO의 Chevron/SK Enmove/ONEOK/EPD/MPLX/Trans Mountain 등.
- 거래 상대 11곳에 역할을 설명하는 연결 페이지. MPLX에는 모회사 공시로
  확인한 역할 요약을 추가했다. 이 자료를 해당 기업 전체 분석 완료로 세지 않는다.
- Chevron의 기존 관계를 보존하면서 Phillips 66·CPChem·HF Sinclair 관계를 추가.

## 중요한 범위 구분

- PSX는 2025-10-01 WRB 잔여 지분을 인수했으므로 Cenovus를 현재 공동 소유자로
  추가하지 않았다. Los Angeles는 생산 중단·유휴화 단계로 표시했다.
- HF Sinclair의 윤활유 분리·Mississauga 기유 정제 폐쇄는 계획이다.
  2026-08-03 Chevron/SK Enmove 계약과 2027년 하반기 공급 구조 전환 목표를 구분한다.
- 원료를 운송하는 EPD/ONEOK/Trans Mountain을 원료 자체의 매도인으로 추정하지 않는다.
- DINO의 Shell 고객 비중은 2023/2024년 역사적 수치다. 2025년 비중으로 재사용하지 않는다.
- Linde의 PSX 수소 공급은 2021년 공급 개시 발표에 한정한다. 최근 계약량·금액은
  확인한 것으로 표시하지 않는다. 7-Eleven의 계약 기준 물량도 실제 연간 인도량이 아니다.
- CPChem의 전체 매출과 PSX 지분법 이익은 PSX 연결 고객 매출과 구분한다.
- 회사가 특정 경쟁사 이름을 명시하지 않은 경우 공시된 제품·지역 경쟁 범위를 설명한다.
  증시 비교군을 확인된 직접 경쟁관계로 바꾸지 않는다.

## 수치 검수

공식 연차 공시의 인라인 XBRL을 추출하고 원문 표를 다시 읽었다. 출처 URL,
원문 SHA256·바이트 수·수집 시각은 `company_energy_reports.json`에 기록했다.

| 회사 | 2025년 연결 매출(USD) | 대조 결과 |
|---|---:|---|
| MPC | 132,699,000,000 | 외부 3부문 + 기타 5,000,000 일치 |
| PSX | 132,376,000,000 | 제품·지역·외부 부문별 합계 각각 일치 |
| DINO | 26,869,000,000 | 제품 소계/하위 항목 구별 후 제품·부문 합계 일치 |

MPC/PSX의 본사 매출 좌표는 해당 티커+CIK+정확한 단일 XBRL 축/멤버에만
허용했다. 내부거래·제거 좌표나 다른 법인에는 적용하지 않는다.

DINO의 RIN 매각 430,000,000은 기타 매출 746,000,000에 포함된 일부다.
검토한 FY2025 문서·기간에서만 별도 매출 유형으로 옮기고, 제품 합계에 다시
더하지 않는다. 오래된 캐시도 먼저 같은 분류로 맞춰 중복 병합을 방지했다.
숫자·분모·원문 위치는 보존하며 서로 다른 기간·통화·매출 지표를 섞지 않는다.

## 검증·직접 검토

- 전체 회귀: 네트워크 차단 임시 컨테이너, 534개 / 93.432초, OK(17개 Node 검사 제외).
- 호스트 Node/프런트엔드·구조 검사: 20개 / 2.994초, 모두 성공.
- 핵심 자료·매출·기존 기업/관계도 검사: 70개 / 4.373초 성공.
- 최종 패키지 이미지: 동일 핵심 검사 70개 / 1.855초 성공.
- 새 회귀는 자료 계약·출처/연결 페이지, 원문 합계, 본사 좌표 범위,
  오래된 RIN 캐시 중복/멱등성, 계획/역사적 거래 범위를 확인한다.
- 0보다 크고 0.01%보다 작은 매출 비중은 `0%`로 잘못 보이지 않도록 `0.01% 미만`으로
  표시한다. 실제 0과 구별하는 Node 회귀를 추가했다.
- 관계 종류·출처 등급이 같으면 사업 설명이 검토된 기업을 먼저 표시한다.
  법인명만 나열한 자회사가 사업을 설명할 수 있는 자회사보다 먼저 나오는 문제를 줄였다.
- 핵심 카드에서 분리한 상세 내용은 사업·제품·운영 요인에 표시한다.
  동일한 검토 문장이 오래된 원자료 부록에도 남아 중복되지 않도록 전체 사실·출처를 대조한다.
- 직접 코드 검토: 정유 자료/공통 출처/수치 좌표를 별도 모듈로 분리.
  출처 원문을 실행하거나 모델을 호출하는 코드가 없다. 새 의존성도 없다.
  기존 HTTPS 출처 검증·문자열 escape·명시적 registry ID 탐색을 유지했다.
- 보안 검토는 이번 변경 범위의 직접 검토와 기존 회귀 검사다.
  새 전역 보안 스캔이나 OCI/KMS 검증을 수행했다는 의미가 아니다. CodeRabbit 미사용.
- 실제 AI API 호출 **0회**. 테스트의 모델·네트워크 응답은 격리된 대역이다.

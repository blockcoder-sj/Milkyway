# 해상·소형 생산·생산수 기업 조사와 검증

## 진행 범위

INR·GFR·EGY·GPRK·GTE·KOS·TALO·WTI·DEC·REPX·HPK·SD·PED·EPSN·TXO·WBI의
한국어 사업·제품·매출·자산·판매·투입 요소·최근 거래를 추가했다. 확인한 사업
상대 38곳에는 역할별 상세 문서를 연결했다. 주 기업 편집은 조사 원장 213곳 중
122곳이며, 나머지 91곳과 기존 자료의 전체 항목·관계 깊이 검수는 계속한다.
편집 수·수집 성공·테스트 통과를 섹터 또는 개별 기업의 전 항목 완료로 계산하지 않는다.

공개되지 않은 거래 상대를 추정하지 않는다. EGY의 익명 구매자, PED의 익명
고객과 운영사 비율은 실명 관계로 바꾸지 않았다. 역할별 상대 문서는 그 기업의
전체 사업을 모두 조사한 문서와 구분한다. 시가총액·귀속 생산량·공동사업 지분을
제품 시장점유율로 사용하지 않는다.

## 발견한 오류와 직접 검토

- GFR 재무 영수증의 중복 `parent_url`이 엄격한 스키마에서 거절되어 기업
  상세 전체에 영향을 줬다. 이 중복 필드를 제거하고 기존 `parent_annual`의
  실제 원본·접수번호·기간 검증을 유지했다.
- 자동 원문을 한글 편집으로 교체하는 조건이 화면 모델에 없는 `cik`를
  참조했다. 검증된 조사 원장의 CIK로 비교한다. 다른 기업 자료·독립적인
  수동 요약은 유지하고 원문 출처는 아래 모음에 남긴다.
- 기존 정리 규칙이 영어 원문과 함께 있는 한국어 번역도 지웠다. 원문 필드가
  이미 있는 경우 번역을 유지하고, 옛 단일 원문만 원문 필드로 이동한다.
- KOS의 서로 다른 회계 기준이 같은 지역 이름으로 충돌하는 문제, EGY의
  같은 지역 매출 중복, 제품/중류 소계·이전 연도 합계의 중복을 수정했다.
- 음수 허용은 일반 추출 규칙에 확대하지 않았다. REPX의 실제 문서·계약
  수입·제품·기간에 한정해 음수를 읽는다. 모델은 음수의 분모/설명과 유한값을
  검사하며 UI는 콤마·음수 표기와 구성비 제외를 검증한다.

새 의존성·인증·권한·주문·DB 스키마·네트워크 경로 변경은 없다. 출처와 본문은
기존 URL 검증과 HTML escaping 경로를 사용한다. 원본·키·개인 데이터는 Git에
포함하지 않는다. 실제 AI 호출·CodeRabbit·새 에이전트·유료 자료 사용은 0이다.
공용 배포 전체 보안 스캔이나 OCI/KMS의 성공을 주장하지 않는다.

## 실제 검증

- 실제 이미지의 전체 678 tests / 63.034초 OK, Node 미설치 18 skip.
- 호스트 화면 모듈 9개 / 24 tests / 1.325초 OK. 후속 음수 표시 검사는 별도로
  다시 실행해 아래 로컬 반영 기록에 추가한다.
- 최종 앱·데이터·검사 파일 14개 SHA-256이 실제 이미지와 일치했다.
- 초기 tmpfs가 root 소유여서 DB 권한 검사가 실패했다. UID/GID를 앱 10001로
  맞춰 검증 환경만 수정했다. 실제 앱의 보안 권한을 변경하지 않았다.
- 이후 전체 실행은 GFR 중복 필드로 153 errors, 그 다음 실행은 원문 교체와
  이전 재무 건수 기대치로 2 failures였다. 실제 결함과 검사를 수정했고 실패한
  실행을 성공으로 계산하지 않는다. 집중 31 tests / 12.740초 OK도 확인했다.

초기 등록·반복 시작을 추가 점검한다. 이 수치는 네트워크·실제 Chrome·전체
Docker VM의 메모리나 실시간 주문 성능을 뜻하지 않는다.

다음은 DK·DKL·PBF·PARR·CVI·CLMT·GLP·CAPL·SGU·SPH·MMLP·NGL·GEL·WKC·

지분법 수입을 먼저 대조한다. 남은 전 기업과 전체 필드 검수까지 작업을 이어간다.

## 최종 패키지 대조

음수 화면 표기의 회귀 검사까지 포함한 호스트 24 tests / 1.289초 OK,
최종 실제 이미지 전체 678 tests / 75.586초 OK(18 Node skip)를 다시 확인했다.
앱·데이터·검사 파일 15개의 SHA-256이 최종 이미지
`0917747ce15f7f66dc5b55e5d3e258aa7acd078f11e2d0b6bbace532915293e9`와 일치했다.
앞선 이미지·초기 실패 결과와 별도 기록이며 실제 화면 결과는 로컬 반영 후 추가한다.

실제 로컬 조회 검사에서는 EGY의 미편집 사업 구성 발췌가 남는 것을 발견했다.
편집된 한국어 매출 구조가 있을 때 해당 자동 발췌도 정리하도록 순수 함수
`company_reviewed_excerpts.py`로 분리했다. 원래 출처·수동 번역·다른 발행기업의
자료·미검토 기업의 원문은 보존한다. 검증된 전신의 재무 출처만 같은 회사의
역사적 CIK로 허용한다. 집중 36 tests / 14.048초 OK이며 최종 패키지와 실제
HTTP 재검사를 계속한다. 첫 로컬 검사는 EGY에서 실패한 실행으로 기록한다.

Chrome 기존 두 탭을 확인했으며 추가 탭을 열지 않았다. 확장 연결은 debugger
연결 오류였고, native 화면에서는 사용자가 해운 리서치 프로젝트를 보고 있어
전환·덮어쓰기하지 않았다. 이 관측을 에너지 화면 검증 성공으로 계산하지 않는다.

## 캐시와 실제 로컬 조회 최종 검증

해결되지 않는다. 검토한 기업·문서·연간 기간의 기존 행에도 같은 매출 태그
선택을 적용했다. 다른 원문·기간의 자료는 이 예외로 지우지 않는다.
집중 23 tests / 0.363초 OK와 옛 캐시·다른 문서 보존 검사를 확인했다.

# 해상 운송 조사와 검증

## 범위와 남은 작업

DHT·FRO·GLNG·FLNG·LPG·INSW·NAT·NVGS·STNG·TEN·TK·TNK·TORO·IMPP·PXS·KNOP
16곳의 한국어 사업, 제품·운영, 계약, 수입 구성과 최근 변경을 추가했다.
95개 관계 상대 프로필은 해당 거래·사업 역할을 설명한다. 상대 회사 전체
조사 완료를 뜻하지 않는다. BW LPG/BWLP와 Robin Energy/RBNE는 공식 종목
확인 후 기존 관계 ID와 연결하며 213개 주 기업 원장에 임의 추가하지 않는다.

현재 조사 원장 213곳 중 주 본문 155곳, 미편집 주 대상 58곳이다. 본문 수를
전 항목 완료 기업 수나 섹터 완료율로 사용하지 않는다. 남은 기업 편집 외에
전체 실제 거래 관계, 법인 동일성, 최신성, 공식 분류, 가독성, 화면 검토가 남아 있다.
이번 중간 검증·커밋·푸시·배포로 작업을 종료하지 않는다.

16개 연차와 LPG/INSW 분기, 총 18개 보관 원본의 크기·SHA-256을 확인했다.
추가 다운로드한 KNOP 분기 PDF·Scorpio 고객 PDF·Toro 9월 발표 PDF 3개도
원본 크기와 SHA-256을 남겼다. 실제 연차 파싱 결과 69행이 보관 표와 일치한다.
재무 보관소는 205개 기록/200개 수치 보유/1,567개 수치다. 누락된 금액을
총계의 차액이나 관계 상대 이름으로 추정해 채우지 않는다.

## 직접 검토와 발견한 문제

- 추가 확장 태그는 정확한 URL·기업·CIK·공시 결산일에만 적용한다. USD 아닌
  캐시, 다른 문서/기간, 중복·상충 좌표, 외국 CIK, typed 차원을 구분한다.
- TEN은 실제 두 구성 태그와 손익계산서 전체가 일치해야 한다. 불완전한 캐시나
  잘못된 태그가 다시 표시되는 회귀 경로를 막았다. 일반 음수 허용을 늘리지 않았다.
- 소계와 하위 구성, 리스·운임·풀 정산·지분법 수입을 따로 처리했다. 기존
  정유·가스·생산사 자료와 공통 상대 설명을 보존했다.
- 검토 행 수를 처음 79로 예상한 검사는 안전하게 실패했고, 실제 합계를
  69로 확인한 후 기록했다. 기대 스키마의 `share_exclusion=None`와 계속사업
  현금흐름 라벨을 수정한 집중 검사도 실제 실패 기록을 보존했다.
- 네트워크 차단 상태에서 기본 Dockerfile의 apt 단계는 실패했다. 기존 검증
  이미지의 정확한 SHA를 기반으로 소스만 덮는 로컬 이미지로 검증했다. 새로운
  의존성 빌드나 의존성 재감사를 했다고 주장하지 않는다.
- `unittest discover -t .`는 tests 폴더의 import 조건에 맞지 않아 실패했다.
  실제 `discover -s tests -v`로 다시 완료했다. 외부 검토 스크립트의 PYTHONPATH
  누락도 수정 후 다시 측정했다. 실패를 성공으로 계산하지 않는다.
- 최초 HTTP 검사는 관계 상대를 원장 종목 경로로 요청해 404를 받았다.
  이는 원장 경계다. 실제 관계 ID 경로는 HTTP 200이며 역관계와 내용을 확인했다.
  검사 출력의 상태 변수 재사용도 분리해 다시 실행했다. API를 임의 확대하지 않았다.

## 실제 검증과 로컬 반영

- 최종 이미지 `27a0a9157119af9237985426c480c31ae1b6afb12b0ab09cff874314465b0cd3`.
- 네트워크 차단·512 MiB·1 CPU: 전체 703 tests / 79.358초 OK, Node 미설치
  18 skip. 이 18개를 포함한 호스트 9개 화면 모듈 21 tests / 1.416초 OK.
- 이미지의 앱/검사 소스 236개 SHA-256 일치. 집중 40 tests / 1.844초,
  최종 이미지 집중 82 tests / 2.278초 OK. 16개 원본 재파싱 69행 일치.
- 격리 SQLite 첫 등록 1,001 entities / 4.816초 / RSS 67.0 MiB / quick_check OK.
  목록 200회 p95 0.745 ms, KNOP 병합 200회 p95 1.445 ms,
  격리 상세 50회 p95 10.582 ms / 최대 RSS 67.7 MiB. 네트워크 시세나 화면
  렌더링 성능을 측정한 수치가 아니다.
- 앱만 재생성해 16곳·관계 상대 4곳·기존 기업 6곳의 실제 HTTP 200을 확인했다.
  69행, 기간·부분합·리스·계속사업 현금, 관계 ID 탐색·역관계가 맞는다.
- startup 200(web/DB), ready 503은 기존 중지한 paper/backtest worker 때문이다.
  DB·dataset·data_gate·personal-data는 true. 페이퍼 매매를 재개하지 않았다.
- 기존 서비스 4개·사용자 데이터·백업 보존. 측정 메모리는 앱 151.1 MiB,
  backup 44.3 / market-data 268.3 / personal-data 240.6 MiB였다. Docker의
  전체 VM이나 Chrome 사용량을 뜻하지 않는다. 검증 컨테이너는 실행 후 제거했다.
- 기존 Chrome 에너지 탭의 제어 연결이 붙지 않아 실제 시각 검수는 남아 있다.
  추가 탭을 열거나 사용자의 별도 조사/학교 창을 변경하지 않았다.

직접 변경·보안 검토에서 새 의존성·권한·인증·주문·SQL·외부 요청 경로 변경은
없다. 기존 URL·수치·문서 크기 검증을 유지했다. .env·키·개인 DB·수집 원본은
Git과 빌드 문맥에 넣지 않았다. 추가 유료 AI 호출·CodeRabbit·새 에이전트·
유료 자료 사용은 0이다. 공용 배포 보안 스캔·OCI/KMS 검증 완료를 주장하지 않는다.

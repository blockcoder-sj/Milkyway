# 에너지 운송·장비·화학 원문 검토 · 2026-10-03

## 전체 작업과 이번 범위

미국 상장 에너지 조사 목록 213개 중 ENB·PBA·TRP·SOBO·TS·SSL 여섯 기업을
추가로 편집했다. 주 기업 편집 수는 81개이며 132개와 전체 항목의 심화 대조가
남아 있다. 이번 묶음이나 수집 개수는 섹터 완료가 아니다. 커밋·배포 이후에도
원자력 연료, 생산, 정유, 해상 운송 등 남은 기업을 계속 조사한다.

기업별 한국어 사업 구조, 제품·설비, 매출 범위, 투입 요소와 공개된 실명 계약을
정리했다. 원문 연차 자료와 최신 기업·정부·실제 공급사 발표만 사용했다.
관계 상대의 역할별 상세 페이지는 그 상대 기업 전체의 완전한 조사를 뜻하지 않는다.
시장점유율을 시총 비중이나 연결 매출 구성 비율로 대신하지 않는다.

## 수치와 원문 대조

재무 원문 영수증은 200개, 수치가 있는 기록은 194개, 재무 수치는 1,503개다.

관측한 재무 첨부만 사용하고 URL·CIK·기간·SHA-256 영수증을 유지했다.

## 직접 코드·보안 검토와 검증

네트워크·모델 호출을 추가하지 않았다. 새로운 로그인·권한·주문·의존성·DB
스키마 변경은 없다. 기존 출처 URL 검증·출력 escaping·CIK/기간/문서 한계를
유지한다. 편집 병합의 재실행 결과와 정방향·역방향 관계 탐색을 검사했다.
CodeRabbit·새 에이전트·유료 데이터·실제 AI 호출은 사용하지 않았다.
전체 공용 배포 보안 스캔·OCI/KMS 성공을 주장하지 않는다.

- 집중 51 tests / 1.923초 OK.

  임시 runtime 쓰기 권한·실행 가능한 임시 테스트 스크립트 설정 누락으로 실패했다.
  검증 전용 실행 조건을 바로잡으며 로컬 앱 보안 설정은 변경하지 않았다.

paper/backtest worker는 false다. 자동매매 워커 전체를 정상 운용 중이라고
주장하지 않는다. 사용자의 runtime·backup 볼륨과 중단 상태를 유지했다.

기존 Chrome 탭 하나에서 PBA의 한국어 사업 정리·분리된 매출 분모·원문 재무,
25개 사업 관계의 8개 단위 페이지 표시를 확인했다. PBA 실제 Yahoo 장 종료
시세는 45.89 USD, 2026-10-02 20:00:02 UTC 기준이다. 새 실시간 체결로
표시하지 않았다. 앱 재시작 중의 연결 표시가 startup 완료·페이지 갱신 후
회복된 것을 확인했다. 관계도의 Siemens Energy 클릭으로 해당 공급사 상세에
이동해 Greenlight·PBA 고객 관계의 역방향 표시도 확인했다. 네 개 기존 서비스만
유지한다.

# Energy 조사·탐색 최종 검토

2026-10-04. 새 PC 복원 이후 중간 마일스톤에서 멈추지 않고 남은 기업 조사,
원문 대조, 실행 앱·Chrome 검수까지 이어갔다. 현재 확정한 발행기업 원장
213개(주 조사 201·산업 연결 12) 범위의 조사·탐색 구현을 마쳤다.
[기업별 검수표](ENERGY_SECTOR_COVERAGE_20261004.md)와 앱의 문장별 출처로
실제 범위·기준일을 확인할 수 있다. 전 세계 모든 기업·공급망의 완전한 목록을
뜻하지 않으며, 공개 자료로 확인되지 않은 수치·상대·진행 상태는 추정하지 않았다.

- 213개 모두 사업·제품·수익 구조·판매 경로·투입·경쟁·운영·최근 변화·관계를

  역할, 전신·승계 법인, 펀드·선물·청산 기업을 구분한다.
- 누락됐던 56개의 연간 재무 비교 범위를 해당 기업의 검토한 매출 원문과
  연결했다. 18개 기업에는 공시 사업을 바탕으로 한 경쟁 비교 기준을 추가하고
  사업 분석임을 표시했다. 비교 대상을 실제 고객·경쟁 계약으로 만들지 않았다.
- 최신 자료가 본문에 덜 반영된 21개 기업의 분기·후속 원문을 다시 읽었다.
  CAPL/CNQ/CNX/CRGY/CVI/DTI/DTM/GEL/HP/LTBR/MGY/MTDR/PR/RES/SGU/
  SND/TTE/VTS/WKC/PBR/YPF의 실제 변화·지표 범위를 보완했다. NC의 계약 의무와
  실제 인계 미확인 상태도 따로 기록했다.
- 연간 재무와 최신 분기를 합산하지 않았다. HP·SGU의 6월 종료 분기는 각각
  FY2026 Q3다. CNX의 현금 헤지 포함 비GAAP 매출, VTS 직접 운영 자산의 익명
  고객 집중, PR 유종별 증감, SND 전체 매출과 모래 물량의 분모도 분리했다.

## 복구한 데이터에서 발생한 결함

1. `profrac` 등 정확히 검토한 비상장 역할 ID가 상장 종목에 연결됐을 때
   공개 연간 재무 보강 경로를 건너뛰었다. 티커 직접 조회와 같은 보강 경로로
   수정하고 등록 별칭 전체에 대한 회귀 검증을 추가했다. 새 프로필 검증만으로
   발견되지 않았으며 복구한 실제 앱 ACDC 화면에서 재무표를 확인했다.
2. 같은 문서의 과거 관계 문장이 나중에 수집됐다는 이유로 대표 근거가 됐다.
   원문 등급→실제 문서 날짜→같은 문서의 현재 검토 문장 순서로 정렬한다.
   수집일 표기는 문서 날짜로 해석하지 않는다. 과거 근거는 지우지 않고
   역방향 상세에서도 보존한다. 새 문서·provider 등급·역방향 회귀를 검사했다.
3. 같은 재무 범위 설명이 복구 캐시에 남아 중복 표시됐다. 정확히 같은
   문서·날짜·설명을 한 번 표시하며 다른 기간·자료는 보존한다.
4. 자동 수집의 SEC 실패 메시지와 별도로 편집한 OTC·공시 재무를 구분해
   설명한다. 실패 자체는 숨기지 않는다. Chrome 캐시가 예전 JS를 사용하던
   상황도 발견해 기업 화면 자산 버전을 갱신했다.
5. 자동 수집이 요청·대기열 한도에 걸려도 확보한 본문·재무는 유지하고
   갱신 대기 상태로 설명한다. 기존 수집 오류·수동 요청 실패는 그대로 확인할 수 있다.

## 실제 검사 증거

- 전체 Python 763개/22.381초 통과, 18개 skip. skip은 이미지에 Node가 없는 화면 검사
  범위이며 호스트 Node 화면 검사 21개/0.579초가 별도로 통과했다.
  실행 앱과 호스트의 코드·공개 데이터·테스트 271개 파일 SHA가 일치했다.
  최종 이미지 ID는 `sha256:d3b2f4fde547e00766e108deae4f4df06605e0fa74f225ca682558afc19be5da`다.
- 213개 전체의 필수 본문·재무 범위·관계·원문 출처 누락 0, 반복 보강 결과
  변화 0, 탐색 그룹 미분류 0. 1,399개 매출 행·1,652개 연간 재무 행을 보존한다.
  이 개수는 새 편집 프로필 기준이며 복구한 과거 근거를 합친 화면 건수와 다를 수 있다.
- 실제 로컬 인증으로 213개 기업과 연결 기업 3,643개를 HTTP 조회했고 역방향
  관계를 확인했다. 이 중 2,779개는 부속 명세 등 출처만 있는 탐색 항목이다.
  이들을 완전한 사업 분석 프로필로 세지 않는다. MUR의 51개 명세 법인에도
  확인되지 않은 영업 역할을 붙이지 않았다.
- 기존 Chrome 탭 하나에서 213개 고유 기업을 방문해 한국어 본문·제품·실적
  요인·재무표·범위·원문 링크를 검사했다. 빈 필수 영역·페이지 전체 가로 넘침은 0.
  추가 실제 화면에서 ACDC의 복구 재무표, NXE의 세전 손익 라벨·중복 없는 범위,
  AMEN의 기존 수집 오류와 별도 OTC 재무, MGY의 거래 필터를 확인했다.
  MGY→WildFire Intermediate 거래 대상→MGY 역방향 이동과 원문 근거 패널을
  눌렀고 SEC 원문 페이지에서 9월 10일 완료·대상의 직후 합병 문장도 확인했다.
- 빠른 전수 이동 중 42개에서 기업 자료 수집 요청 제한을 확인했다. 이는 가격
  갱신 제한이 아니라 자동 자료 수집 POST의 60회/시간 제한이다. 재검사 중에는
  수집기가 중지된 상태에서 200개 대기열 한도도 확인했다. 본문·재무는 정상
  표시됐고 어느 제한이나 기존 대기 요청도 삭제하지 않았다. 두 묶음으로 42개를
  재검사했으며 요청 횟수 제한 경고는 0이었다. 대기열 한도·원문 수집 오류는
  갱신 상태와 확보한 자료를 분리해 표시한다. 첫 전수 검사에서 확인한 자동
  수집 오류 10개 외에 재검사에서 드러난 기록도 숨기지 않는다.
  최종 JS `20261004-energy-final-2`를 새로 읽은 PXS 화면에서는 대기열 한도가
  갱신 상태에 표시되고 본문 오류는 비어 있었으며 재무 8행은 유지됐다.
  수동 요청의 실패와 기존 수집 오류가 남는 동작은 호스트 회귀 검사로 확인했다.
- 512 MiB·1 CPU·외부 네트워크 없는 임시 컨테이너에서 SQLite quick_check 정상.
  seed 1,178개/1.003초, 목록 213개 p95 .149 ms, 전체 213개 상세 p95 7.240 ms,
  최대 17.250 ms, 최대 RSS 73,240 KiB다. 성능은
  `runtime/verification-20261004/completion-benchmark.json`에 기록한다.
  네트워크·브로커·다중 사용자 부하 성능을 뜻하지 않는다.
- 실제 로그·원문 수신 영수증·API 요약은 `runtime/verification-20261004/`에 보존한다.
  Chrome 검사 요약은 `chrome-summary.json`, 포장 일치는
  `completion-code-manifest.json`에 기록했다.
  분기 HTML 17개의 이번 수신 SHA는 이전 영수증과 달랐다. 이전 SHA를
  성공 증거로 바꾸지 않고 이번 바이트·SHA를 따로 기록했다. 추가 공식 원문 7개와
  NXE 재무 원문도 확보했다. 과거 388개 영수증 전체의 원본을 이 PC에서 다시
  검증했다고 주장하지 않는다.

이번 최종 원문·공개 검사 증거는
`runtime/handoff/milkyway-energy-final-review-20261004.zip`에 별도로 묶었다.
SHA-256·ZIP CRC·수신 영수증의 원문 SHA를 확인했으며 이전 조사 묶음은 보존한다.
이 추가 ZIP은 Git 밖의 파일이다. 다른 컴퓨터로 이동할 때 `.sha256`·`.summary.json`과
함께 가져간다. 개인 DB·키·`.env`·볼륨을 포함하지 않는다.

## 직접 코드·보안·품질 검토

정확한 종목·등록 별칭과 원문 좌표만 사용한다. 이름 유사성으로 법인을 합치지
않으며 관계 SQL은 기존 매개변수 조회·400행 한도를 유지한다. 날짜 정렬과
한국어 표시 변경에는 외부 호출·사용자 코드 실행·새 의존성이 없다. 기존 인증,
CSRF, 경로·출처·프로필 제한, 보존·회귀 검사도 전체 suite에서 통과했다.
작업 범위의 직접 코드 검토이며 별도 독립 agent·CodeRabbit 검토는 하지 않았다.

실제 AI 호출 0, CodeRabbit 0, 새 agent 0, 유료 자료 0. 개인 DB·키·`.env`·백업·
runtime·개인 볼륨과 다른 사용자 앱을 보존한다. 공개 커밋에는 코드·공개 데이터·
검토 문서만 포함한다. 임시 검증 컨테이너는 `--rm`으로 제거된다.

## 남는 자료·운영 한계

정적 연구는 원문 날짜의 공개 사실이다. 익명 고객·제품별 미공개/미확보 분할·
검증된 시장점유율·NC Sabine 실제 인계 완료 같은 확인되지 않은 사항은 본문에
범위를 표시했고 가상 수치·관계를 만들지 않았다. 다음 분기·새 공시는 재검토해야 한다.

개인 로컬 연구 앱의 기능 검증과 브로커 피드·페이퍼/백테스트·공개 배포는 별도다.
멈춘 운용 worker·기존 피드 실패 때문에 readiness 503이 남는 상태이며, 신선한
브로커 시세나 연속 실운용을 성공했다고 표시하지 않는다. 공개 OCI/KMS 배포는
기존 보안 게이트의 NO-GO를 유지한다. 이 세션에서 Deep Scan을 수행하지 않았다.

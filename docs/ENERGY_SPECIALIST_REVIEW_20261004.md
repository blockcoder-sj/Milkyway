## 기능·성능·코드·보안 증거

- 최종 이미지 전체 검사: 721개, 20.748초, 통과. 컨테이너 Node 부재로 18개
  건너뜀. 별도 호스트 Node 연계 9개 모듈 검사 21개는 0.628초, 모두 통과.
- 새 회귀 검사 5개: 실제 화면용 enrichment에 매출이 전달되는지, 별도 보기
  합계, 원문 음수, 익명 고객·제품 브랜드, 실제 관계와 역방향 이동, 차원·
  통화·CIK·다른 문서/기간·캐시 충돌을 확인한다.
- 초기 성능/API 검사가 매출 enrichment 연결 누락을 발견했다. 연결과 회귀
  검사를 수정하고 이미지를 다시 빌드했다. 최종 전체·성능·실제 API 검사는
  수정된 동일 이미지에서 통과했다. 초기 실패 로그도 보존한다.
- 소스를 직접 읽어 출처·기간·내부거래·지분법·비에너지 범위, 등록 ID·역방향
  관계·캐시 보존 경로를 검토했다. `git diff --check` 통과.
- 원문 파서·좌표는 네트워크/모델 호출 없이 작동한다. 기존 권한·credential
  처리·거래 실행을 변경하지 않았다. 실제 AI 공급자 호출 0회, CodeRabbit 0회.
  공개 배포·OCI/KMS 게이트는 별도이며 세션의 disabled 권한으로 Deep Scan은
  실행하지 않았다.
- 네트워크 차단·1 CPU·512 MiB 제한의 임시 컨테이너: 1,066 entity 초기화
  0.873초, SQLite quick_check `ok`. 213개 목록 50회 p95 0.140ms,
  상세 15회 p95 6.073ms, 최대 RSS 69,000 KiB. 실제 회원 feed·거래 연속 운영
  성능을 뜻하지 않는다.
- 포장된 코드·공개 데이터 274개 파일의 SHA-256과 로컬 검토 소스 일치.
- 앱만 새 이미지로 교체했다. 실제 앱 이미지
  `sha256:44daf767ed258b0c33db55cce72db78a6ea26dc921943ad6c82bb2d24d5d123b`,
  컨테이너 healthy·startup 200. 개인/시장 데이터·backup 및 볼륨 보존.
- 정상 local auth를 통한 5개 신규+6개 기존 상세 API 200, 신규 매출 총 49행,
  PHX·GDi·OneSubsea 상세·역방향 관계 확인. 검증 세션은 logout으로 종료.
- 기존 Chrome 탭 하나에서 5개 제목·한국어 제품·매출·관계 표시를 확인했다.
  Forum 제품 표의 -502,000과 조정 포함 비중 제외를 실제 스크린샷으로 확인.
  PHX 링크를 클릭해 설명과 NESR 역방향 관계를 확인했다. 재시작 중 연결 실패
  화면은 앱 기동 후 새로고침해 정상 상태를 확인했다.

상세 로그·수신 영수증·성능·이미지 파일 대조는 git 제외 경로

# 광물권·로열티·토지 조사와 검증

2026-10-04, Asia/Seoul. BSM·CRT·DMLP·KRP·NRP·NRT·PBT·SBR·TPL·VNOM·CKX·
MNR·MXC·LB·PNRG 15곳의 저장된 조사 초안을 원문과 대조하고 앱에 연결했다.
58개 관계 상대 설명과 115개 출처별 관계를 포함한다. 상대의 회사 전체 조사나
15개 주 기업의 모든 필수 항목 완료를 뜻하지 않는다.

213개 원장 중 주 본문 편집은 170개이며 남은 주 대상은 43개다. 전체 깊이·
현재성·법인 동일성·공식 분류·한국어 가독성·관계와 화면 검수를 계속한다.
이번 검토·커밋·푸시는 다음 작업으로 이어지는 중간 체크포인트다.

## 원문과 금액

15개 연차·분기, 총 30개 보관 원본의 SHA-256·크기가 수신 영수증과 일치했다.
11곳의 비인라인 신탁 외 연차를 다시 파싱해 58개 실제 매출 행을 얻었다.
CRT·NRT·PBT·SBR는 원문 표의 재무 28개 값과 매출 11개 값을 수동 대조했다.
신탁 표에는 실제 원문 캡션과 문서 앵커를 사용하며 XBRL 추출로 설명하지 않는다.
15개 전체 매출 표는 69행이다.

## 코드·품질·보안 검토

- 사업별 탐색에 광물권·로열티와 토지·용수 그룹을 추가했다. 탐색 분류는 공식
  GICS 코드와 별도다. NRP는 석탄·광물, MNR·MXC·PNRG는 생산 사업으로 연결한다.
- 기존 NSAI 관계 ID에 Mach 설명을 추가해 GPOR 등 기존 탐색을 유지했다.
  Cawley Gillespie와 WBI의 기존 프로필·관계도 함께 보존했다.
- 음수 파생상품·처분손익은 검토한 정확한 URL·기업·CIK·기간·태그에만 허용한다.
  다차원 중복·추가 차원·잘못된 통화·기간·문서·상충 값 검사도 유지했다.
- 실제 Chrome 검사에서 시세 제공사 이름이 잘리는 문제를 발견했다. 검토된 주
  기업의 이름을 사용하도록 수정하고 멱등성·기존 전체 검사로 회귀를 확인했다.
- 인증·주문·권한·네트워크 요청·DB 스키마·의존성 변경은 없다. 본문·관계·URL은
  기존 스키마와 이스케이프 경로로 표시한다. 공개 코드만 Git에 포함하며 개인
  DB·키·.env·백업·수신 원문은 보존하고 Git과 빌드 문맥에서 제외한다.
- 직접 소스·원문·변경 범위를 검토했다. 새 독립 에이전트·CodeRabbit·유료 AI
  호출은 0이다. 전체 새 보안 감사나 공용 OCI/KMS 게이트 완료를 주장하지 않는다.

## 실제 실행 증거

- 최종 이미지: `82e07a5a6ef28496d36e1e63ffbc0202953b97ba440c04641034c1dd19a1e8ad`.
  현재 검토한 공개 앱·검사·배포 소스 271개가 이미지와 SHA-256 일치한다.
  기본 Dockerfile 빌드는 기존 의존성 캐시를 재사용했으며 새 의존성 재감사가 아니다.
- 네트워크 없는 512MiB·1 CPU, 읽기 전용 이미지: 전체 716 tests / 20.631초 OK,
  Node 없는 이미지에서 18 skip. 해당 화면 스크립트를 포함한 호스트 9개 모듈
  21 tests / 0.622초 OK. 집중 12 tests / 0.239초 OK.
- 초기 전체 실행 3회는 임시 DB·키 디렉터리의 읽기 전용/소유권 설정 문제로
  실패했다. 기존 개인 볼륨 대신 소유권이 맞는 임시 저장소로 수정 후 통과했다.
  실패 로그를 보존하며 실패를 통과에 계산하지 않는다.
- 최종 이미지의 격리 등록: 1,060 entities / 0.849초 / SQLite quick_check OK.
  213개 목록 조회 50회 p95 0.135ms, 15개 상세 45회 p95 5.566ms,
  최대 RSS 67.1MiB. 이는 오프라인 로컬 데이터 함수이며 브라우저나 시세 성능이 아니다.
- 앱만 재생성했다. 15곳·기존 기업 6곳 HTTP 200, 69행과 관계 상대의 역관계 확인.
  최초 무인증 요청은 401로 거부됐다. 정상 로컬 인증 API로 검증한 임시 세션은
  로그아웃했다. 토큰·계정·개인 원장 값을 로그에 내보내지 않았다.
- 사용자 Chrome의 기존 탭 하나로 15곳의 제목·매출·관계 영역을 실제 확인했다.
  로열티 그룹의 8개 결과, PBT의 원문 차이와 9월 발표, Argent의 역관계,
  LB의 관련자별 10행과 전환 예정 상태를 확인했다. PBT에 보이는 예전 SEC 자동
  수집 404 경고는 성공으로 바꾸지 않았으며 대조한 신탁 표는 표시된다.
- startup 200, app healthy. ready 503은 중단한 paper/backtest worker 때문이다.
  기존 서비스 4개·개인 런타임·원본 백업·다른 프로젝트 볼륨을 보존했다.

원본 영수증, 재파싱, 표 대조, 실패·통과 로그, 코드 SHA와 성능·HTTP 결과는
Git 제외 경로 `runtime/verification-20261004/`에 보존한다. 이어서 남은 시추·
해양 서비스·석탄·가스/LNG·소형 발행기업 및 전 항목 검수를 계속한다.

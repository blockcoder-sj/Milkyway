# 미국 상장 통합 에너지 기업 자료 검토 · 2026-10-03

## 작업 범위와 전체 목표

미국 에너지 섹터 전체 작업을 계속하는 중간 마일스톤이다. 이 문서·커밋·배포를
섹터 완료로 보고하지 않는다. 목록 등재, 원문 수신, 재무 값 추출, 한국어 자료
정리와 공급·고객 관계 검토는 각각 다른 단계다.

- 현재 미국 상장 식별을 추가한 조사 목록은 213개다. 공식 GICS 전체 분류표나
  조사 완료 기업 수가 아니다. 기존 공식 분류가 있으면 탐색 힌트보다 우선한다.
- 이번 상세 정리: XOM, SHEL, BP, TTE, E, EQNR, PBR, EC, YPF.
- 사업·제품·판매 경로·투입 요소·사업 조건과 날짜가 있는 계약·개발·지배 구조를
  한국어로 편집했다. 익명 고객·공급자·미공개 계약을 추정하지 않는다.
- 기업 관계는 실제 공급·구매·공동사업 역할과 프로젝트 범위를 기록한다.
  관계 상대 상세와 역방향 탐색도 검증한다.
- 다른 이번 신규 목록: SU/CNQ/IMO/CVE/OBE/BTE/VET/TS/PDS/SSL 및
  CCJ/DNN/NXE/EU/UUUU. 이들의 심층 사업 정리는 다음 작업이며 목록 추가로
  완료 판정하지 않는다. 원자력 연료·복합 사업은 산업 연결 범위를 표시한다.

## 원문 수신과 재무 검토

23개 현행 SEC 종목·법인·거래소를 대조하고 연차 원문을 수신했다. BP는 최초
24 MiB 연구 다운로드 한도를 넘었다. 별도 원문 읽기 작업으로 29,303,585 byte
원본을 수신했고 SHA-256·수신 시간을 보존했다. 앱의 네트워크 수집 한도는
확대하지 않았다. 정적 수신 영수증의 byte 메타데이터만 48 MiB까지 검증한다.

BP의 중첩된 `31 December 2025` 영문 일·월·년 변환을 지원해 연차 재무가
누락되는 문제를 수정했다. IFRS 고객 계약 매출 표준 태그도 지원한다.
법인 CIK, 원문 URL, XBRL 문맥, 연결 범위, 연간 기간, 통화·단위를 대조한다.
부채 등 없는 태그는 다른 숫자 차액으로 만들지 않고 손실 부호를 유지한다.

이번 9개 기업에서 72개 원문 재무 값과 126개 매출 구성 행을 검토했다.
전체 재무 영수증은 190개, 재무 값이 있는 영수증은 181개, 값은 1,408개다.
이 수는 사업 분석 또는 섹터 완성도를 뜻하지 않는다. 기존 9개 빈 영수증의
첨부 재무제표·일반 표 검토도 남아 있다.

TTE·EC·BP의 연구용 문단 추출은 25,000개에서 제한됐다. 원본 HTML·해시는
보존했고 재무·매출 XBRL은 전체 원본에서 별도로 읽었다. 모든 문단을 분석한
것으로 보고하지 않는다. 40-F/6-K 표지만 받은 경우 실제 첨부를 별도로 찾는다.

## 날짜·사업 역할 검토 사례

- Shell: ARC 인수 완료 2026-09-02; LNG Canada 2단계 FID 2026-09-29.
  현재 1단계 14 Mtpa와 장래 28 Mtpa를 구분. 각 공동사업자의 가스 조달·LNG
  인수와 JGC·Fluor EPC 역할을 별도로 연결한다.
- Shell·Equinor: Adura 설립 완료 2025-12-01, 각각 50%. 이전한 UK 생산 자산과
  각사가 남긴 자산을 구분한다.
- Eni: Plenitude의 2026-10-01 공동 지배 전환·연결 제외. 65.03% 소유를 단독
  연결 지배로 해석하지 않는다. 2025년 연결 재무와 현재 범위가 다르다.
- BP: 2026-06말 보고의 Castrol 65% 매각 계약은 잔여 조건·연말 완료 목표가
  있는 거래로 표시한다. 현재 완료됐다는 근거를 만들지 않는다.
- XOM: Nucor·NG3의 CCS 상업 운영과 과거 조건부 Baytown 계획·중지 상태를
  구분한다. Hammerhead의 계약·향후 첫 생산, Golden Pass 첫 train의 LNG
  생산을 전체 설비 가동 완료로 확대하지 않는다.
- PBR: YPFB 가스 공급과 GTB/TBG/TAG/NTS 수송은 다른 거래 역할이다.
- EC·PBR: Sirius 17개 상대방·66개 조건부 계약을 현재 생산으로 표시하거나
  공개되지 않은 고객 명단으로 채우지 않는다.
- YPF: 현지 보통주 1:10 분할과 ADR 비율 변경을 NYSE ADR 분할로 적용하지 않는다.
- FTK: Exhibit21.1의 실제 네 자회사·관할을 검토해 보강. 같은 기업·공시·날짜의
  기존 일반 추출만 대체하며 다른 사업 역할·다른 공시 근거는 보존한다.

## 코드·보안·기능 검토

직접 소스를 검토했다. CodeRabbit, 실제 AI provider, 실거래 주문은 사용하지
않았다. SQL 스키마·암호화·권한·주문 실행·의존성 변경도 없다.

- 기존 요약과 새 요약을 합쳐 카드 상한을 넘는 XOM 오류를 발견해 수정했다.
  검토된 요약으로 교체하고 과거 출처는 출처 모음에 남긴다.
- 출처 승격 후 중복·반복 병합을 정리해 재실행 결과가 동일하도록 검증한다.
- 외부 HTML은 실행하지 않고 고정 자료와 안전한 출처 URL로만 사용한다.
  정적 자료 크기·행 수·출처·기간·재무 좌표 검증을 유지한다.
- 시세 미연결 기업·기관을 모두 비상장으로 부르는 문구를 수정했다.
  수집 요청 파일이 있다는 이유로 실제 수집 중이라고 표시하지 않는다.
- 전역 `:workspace` 관리 권한이 없는 세션이므로 새 전체 보안 스캔·실제 OCI
  배포 보안 통과를 주장하지 않는다. 이번 소스 변경 범위의 검토·회귀 증거다.

## 로컬 앱 반영과 실제 화면

- 최종 이미지 `000037b7d025b715a4e81cee90aabf862f659566039cfed0e58cebbe1deb4867`.
  변경 앱 파일 16개의 SHA-256이 원본과 실제 패키지에서 모두 일치했다.
- 앱 서비스만 `--no-deps --no-build`로 반영했다. `/health/startup`의
  `web_and_database` 준비 완료와 컨테이너 healthy를 확인했다.
- 기존 Chrome 탭 하나에서 Shell의 한국어 요약·수치·동일 기준 매출 비중과
  원문 연간 재무, 관계 2페이지를 확인했다. 관계도 → LNG Canada 상세 이동과
  JGC·Fluor 공급 역할·다섯 공동사업자의 가스 공급/LNG 인수 역할도 표시됐다.
- 실제 AI 호출은 0회다. 개인 런타임·백업 볼륨을 보존하고 기존 네 서비스만
  계속 실행했다. 회사 자료 수집기를 중지한 상태라는 화면 안내를 유지한다.

## 이어서 할 작업

캐나다 생산·정유, 배관·운송, 해상·시추, 기타 잔여 기업·산업 연결 분야를
계속 정리한다. 원문·사업·매출·제품·거래·주요 자산·투입 요소·날짜의 항목별
증거 검토를 남겨, 부분 자료를 전체 기업·섹터 완료로 표시하지 않는다.
미공개 거래·제품별 전체 시장점유율은 공개 근거의 범위를 넘겨 만들지 않는다.

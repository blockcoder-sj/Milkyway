# 무료 자료 추가 조사 종료 기록

사용자가 추가 조사를 시도하되 오래 끌거나 무료 자료·공시의 한계가 드러나면
바로 마무리하도록 요청했다. 2026-10-04 기존 미확보 항목 중 보완 가능성이 높은
연간 매출 범위·익명 고객·거래 완료 여부·관계 상대의 설명을 우선 확인했다.
무제한으로 수천 개 명세 법인을 조사하거나 검색 실패를 미공개 증거로 삼지 않았다.

## 확보하여 반영한 내용

- LBRT FY2025 원문의 비관련자 매출 4,000,269,000 USD·관련자 매출 5,847,000 USD와
  총계 4,006,116,000 USD를 표에 추가했다. 제품·서비스별 분할과 연결 내부거래는 아니다.
  [직접 근거](https://www.sec.gov/Archives/edgar/data/1694028/000169402826000006/lbrt-20251231.htm).
- EU FY2025 주석 18의 익명 외부 고객 세 곳 매출 27,231,000·10,980,000·4,944,000 USD가
  총매출 43,155,000 USD와 일치함을 반영했다. 반올림 비율 합계 99%에서
  가상의 네 번째 고객을 만들지 않았다.
  [직접 근거](https://www.sec.gov/Archives/edgar/data/1500881/000162828026022507/encr-20251231.htm).

## 여기서 중단하는 항목과 이유

| 항목 | 확인한 범위와 종료 사유 |
|---|---|
| LBRT 제품별 매출 | 연차·분기·공식 연차 IR를 확인. 단일 보고 사업이며 관련자 구분을 제품별 분할로 바꿀 수 없음 |
| EU 고객 이름·광산별 매출 | 연차 수익 인식·고객 집중·주석 18 확인. 익명 금액은 확보했지만 이름·광산 배분은 확인되지 않음 |
| AMEN 원유/가스 개별 판매액 | 확보한 FY2025 미감사 연차 손익과 수익 인식 주석은 Oil and Gas 통합 매출. 지분법 이익은 영업 외이며 개별 유종 매출을 추정할 근거 부족 |
| UNTC 제품별 판매액 | 공식 FY2025 실적·IR 공시 페이지 확인. 지속 사업 합계와 생산량·평균가격은 확보됐지만 개별 실제 판매액을 확인하지 못함. 반올림 가격×물량으로 만들지 않음 |
| LTBR/NEXT/NUCL/NXE/TBN | 기존 원문상 해당 연간 기간은 개발·건설·판매 전 단계. 새 매출 행이나 제품별 가상 0 구성표를 추가할 이유 없음 |
| NC Sabine 인계 | NACCO 공식 IR·SEC와 SWEPCO 공식 뉴스 검색에서 계약상 의무만 재확인. 실제 완료를 입증할 후속 원문은 이 제한된 조사에서 확보하지 못함 |
| 출처만 있는 연결 항목 | 실제 API 검사에서 704개 사업 관계 상대 중 43개에 별도 사업 요약이 없었음. 모든 연결 항목 2,779개가 같은 깊이의 조사 공백은 아니며 부속 명세·법인 이름만으로 독립 영업 역할을 만들지 않음 |

이 결과는 무료 자료로 영원히 불가능함을 증명한 것이 아니다. 확인한 문서에서
추가 분할·이름·현재 상태를 확보하지 못했고, 추가 탐색의 효율이 낮아 사용자의
요청대로 이 조사 묶음을 종료한다. 새 공시·구체적 새 출처가 생기면 다시 확인할 수 있다.
수신 영수증·원문·사업 관계 공백 목록은 `runtime/verification-20261004/extra-research/`에 보존한다.
이후 사용자가 요청한 기업별·섹터 전체 3차원 관계도 구현은 별도 기능 작업으로 계속한다.

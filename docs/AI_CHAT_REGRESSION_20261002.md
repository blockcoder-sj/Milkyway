## 발견한 설명 문제와 수정

- 3회차는 전체 자산 기준 16%를 설명하면서, 투자금 안에서의 20%와 전체 자산
  대비 상한 20%를 같은 기준처럼 표현했다. 저장 규격은 정확했지만 설명은
  혼동을 일으킬 수 있었다. 2회차의 휴장일 표현도 "가장 가까운 거래일"로 모호했다.
- 앱의 AI 지침에 `min(투자 비중 / 편입 수, 종목당 상한)`과 전체 자산이라는
  분모를 명시했다. 80%·5종목·20% 상한이면 종목당 16%, 현금 20%이고 상한에
  걸리지 않는다는 예, 10% 상한이면 현금 50%라는 예를 추가했다.
- 휴장일에는 다음 거래 가능 시점에 실행하며 30달력일은 월말이 아니라는
  설명도 추가했다. 모델·추론 수준·호출 수·출력 상한은 유지했다.
- 4·5회차는 이 지침을 적용한 새 이미지에서 실행했다. 4회차는 전체 자산
  기준 16%, 현금 20%, 상한과의 차이 4%p, 다음 거래일을 정확히 설명했다.
- 실행 규칙 표에도 저장된 규격으로 직접 계산한 비중·현금 예시를 표시한다.
  모델의 산술 문장을 재사용하지 않는다. 상한 적용·수량 유지·빈 종목 목록
  회귀 검사를 추가했고 Chrome에서 16% / 20%, 손절 8%, 비용 0.1%를 확인했다.

기존 응답 기록은 검수 증거로 보존했다. 이 보강이 모든 자유형 설명의 정확성을
보장하지는 않는다. 무응답 처리, 규격 검증, 실제 실행 규칙과 설명 품질은 구분한다.

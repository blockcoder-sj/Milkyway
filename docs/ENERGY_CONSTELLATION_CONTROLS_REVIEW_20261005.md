## 반영한 동작

기업·Energy 섹터 공통 Canvas 장면에 적용했다.

- 일반 왼쪽 드래그는 화면을 가로·세로로 이동한다. Shift+왼쪽 드래그는 3D 회전한다.
  드래그 중 Shift를 누르거나 놓으면 즉시 동작이 전환된다. 클릭과 드래그를 구분하므로
  이동 중 천체가 선택되지 않는다. 기존 동작 선택 메뉴는 제거했다.
- 가운데·오른쪽 드래그, 한 손가락은 이동이다. 두 손가락 중심 이동·핀치 확대와
  가로 트랙패드 이동, 휠 확대, 키보드 조작은 유지한다. 2D에서는 Shift 드래그도 이동한다.
- `처음 화면`은 원래 기업/섹터 중심의 전체 지도, 초기 카메라 위치·배율·회전,
  3D·주요 이름·기본 의미 배치/비중·자료 검색 설정으로 돌아간다. 검색 결과·분석 패널·
  마지막 선택·자동 회전·크게 보기를 초기화한다. 초기화 이전 비동기 검색/분석 결과가
  뒤늦게 도착해도 다시 표시하지 않는다. 데이터 재수집·페이지 재로그인은 하지 않는다.
- `전체 지도`/`전체 지도로 돌아가기`는 현재 표시 설정을 유지하며 원래 전체 지도에
  복귀한다. `선택 주변`은 마지막 선택을 다시 확대한다. Escape도 전체 지도로 복귀한다.
- 관계 단계별 반경·그룹 내 간격 증가를 더 줄였다. 의미 군집 방향, 실제 관계,
  매출 비중 우선순위, 전체 요소·연결은 유지한다. 겹침을 허용하고 확대·이동으로 탐색한다.

현재 7,435개 요소/8,114개 연결의 동일한 의미 배치에서 기본 반경은 직접 연결

170.58→99.57, 평균 반경157.30→87.06으로 줄었다. 560px 높이·동일 기준 카메라의
평균 화면 중심 거리는119.55→70.64px, **40.91% 축소**다. 자동 맞춤이 축소 효과를

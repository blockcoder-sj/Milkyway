# 미국 Energy 백과 조사·검수 기준

상태: **진행 중 · 섹터 완료 아님**. 기준일 2026-10-02.

사용자가 요청한 완료는 업계 구조와 개별 기업을 이어서 이해할 수 있는
포괄적인 백과다. 주요 기업 몇 곳, 원문 자동 추출 건수, 관계 수, 자료 수신
성공만으로 완료를 선언하지 않는다.

## 마일스톤

1. **대상과 산업 구조** — 활성 기업·역사적 기업·파생상품 구별, 공식 분류 근거,
   세부 업종, 유통·생산 과정, 용어·계산법, 조사 대상과 누락 상태.
2. **전 기업 사업 분석** — 사업·제품·서비스, 부문/지역별 매출, 설비·생산량·자산,
   판매 경로, 투입 원료·운영 비용·설비투자, 재무·공시의 비교 범위와 기준일.
3. **거래·기술 관계** — 공급/장비/서비스, 고객/판매계약, 공동사업/기술협력,
   경쟁 범위, 주요 자회사. 계약 대상·프로젝트·상태와 근거를 각각 표시.
4. **탐색·갱신** — 기업 상세로 이동, 관련 산업/비상장/해외 기업 연결, 검색·페이지,
   합병 전후와 계획/실행 구별, 한국어 요약·원문·출처, 갱신·누락 표시.
5. **최종 검수** — 전수 누락 검사, 관계 방향·시점·출처 검증, 수치/단위/분모 확인,
   UI·기능·성능·보안·직접 코드 검토, 테스트·커밋·푸시 및 실제 화면 확인.

## 대상 원칙

- GICS Energy의 7개 세부 업종을 산업 구조의 기준으로 삼는다. 개별 기업의
  공식 GICS 코드와 사업 내용으로 정리한 탐색용 분류는 구별한다.
- ITOT/XLE 구성은 무료로 검증 가능한 출발 목록이며 미국 전체 기업 원장이
  아니다. MLP, 소형주, 로열티 권리, 추가 상장기업을 별도 공시와 대조한다.
- 해외·비상장 기업은 중요한 거래 상대 및 산업 구조를 설명하는 대상으로
  포함한다. 이들을 미국 Energy 지수 구성 기업으로 표시하지 않는다.
- 발전·전력장비 등 연결 산업은 원래 섹터를 유지한다. 선물·펀드·현금·청산
  잔여권리는 활동 중인 기업으로 세지 않는다.
- 실제 분석의 기준 시점은 문서별로 남긴다. 새로운 법인의 과거 전신 공시를
  현재 합병 회사의 완전한 실적으로 표시하지 않는다.

## 기업별 필수 검수

| 분야 | 완료 증거 |
|---|---|
| 식별·분류 | 티커/법인/CIK 대조, 공식 근거, 합병·상장 변경 확인 |
| 사업 | 주요 제품·고객 용도·수익 발생 방식의 한국어 설명 |
| 매출 | 부문·지역·제품의 공개 수치, 기간·단위·연결/내부거래 구별 |
| 자산·운영 | 주요 지역·설비·생산/처리량·보유 지분과 총량/귀속량 구별 |
| 원가·투자 | 원료·서비스·물류·에너지·정비·개발 투자와 회사별 영향 경로 |
| 거래 관계 | 각 관계의 주체·방향·상품/역할·기간·현황·공식 출처 |
| 경쟁 | 경쟁하는 구체적 제품/지역, 보고된 사실과 분석용 비교 대상 구별 |
| 자회사·JV | 실질 사업 역할, 연결 범위, 프로젝트 공동 소유와 거래의 구별 |
| 비교 수치 | 시장/상품 범위와 분모가 검증된 경우에만 점유율 표시 |
| 최신 변화 | 최신 분기와 중요 합병·계약·공장 가동 변경 확인 |

각 항목은 `미조사`, `조사 중`, `근거 확인`, `공개 범위 확인`으로 구분한다.
마지막 상태는 확인한 문서·범위와 미공개 내용을 기록해야 한다. 요청 실패,
검색 결과 없음, 추출기 미탐지는 미공개라는 증거가 아니다. 항목에 자료가
있어도 단순 원문 나열이면 한국어 정리 검수 완료로 세지 않는다.

## 자원 운영

사용자의 메모리 절약 요청에 따라 수집/검증은 한 번에 하나씩 실행한다.
현재 company-data, market-details, idle backtest-worker는 중지 상태다.
기존 개인 데이터·백업·페이퍼 세션은 보존한다. 추가 AI API 승인은 없다.

## 2026-10-02 확인된 중간 결과

- GICS 7개 세부 업종, 원료→제품 흐름 7개, 제품·단위 5개, 수치 정의 6개,
  규제·계약 3개 항목을 한국어로 구성했다. 산업 구조와 개별 거래 관계를 구별한다.
- CVX/COP/VLO의 FY2025 사업·매출과 2026년 2분기 변경 사항을 추가했다.
  다차원 매출과 소계의 중복 합산을 수정했고, 각 표의 최상위 합계는 공식
  매출 총계와 일치한다. 일부 거래 상대 6곳에는 역할을 설명하는 문맥 자료를 추가했다.
- 이는 **초기 중간 결과**다. 위 3개 회사도 거래·경쟁·점유율 등을 포함한 전 항목
  완료가 아니며, 나머지 기업과 추가 MLP 전수 조사·대상 확정은 남아 있다.
- 정적 설명·관계는 자동으로 최신 사실이 되는 자료가 아니다. 원문 기준일과
  검토일을 표시하며, 후속 공시·계약 변경은 다시 조사해야 한다.

## 2026-10-02 정유사 후속 작업

  추가했다. 거래 상대 11곳 및 MPLX의 역할 요약을 연결했다.
- 3개 회사 매출 표를 원문 합계와 대조하고 본사 매출 누락, 소계/RIN 중복을 수정했다.

  **6곳도 전체 필수 항목 완료가 아니며, 업종/섹터 완료 기업 수로 표시하지 않는다.**

# Energy · 생산사와 실제 현장 공급망 후속 검토

2026-10-03. 전체 섹터 정리는 계속 진행한다. 이번 8개 기업도 전 필수 항목
완료로 세지 않는다. 무료 공식 자료를 사용했으며 실제 AI 제공사 호출은 0회다.

## 편집한 범위

- EOG/FANG/OXY/DVN/EQT/EXE/AR/RRC의 사업·제품·생산 자산·판매 구조·물류·
  주요 운영비·최근 변경을 한국어로 정리했다. 8개 연차와 8개 분기 원문의
  수신 바이트·SHA256·문서 좌표를 대조했다.
- 생산자 이름이 없는 공급사를 추정하지 않고 ProPetro/Liberty/Smart Sand의
  실제 고객 공시를 역방향으로 연결했다. 공급사 매출 집중도는 고객 원가 비중이 아니다.
- 프로젝트·비상장·외국 거래 상대 27개 문맥 기록을 연결했다. Range 현장 안내는
  실제 역할의 근거지만 발표일이 없어 현재 계약 지속 여부는 미확인으로 표시한다.
- 경쟁 관계는 공시의 사업 범위를 대조한 비교 대상으로 명시한다. 임원 보상용
  peer나 같은 업종이라는 사실을 실제 납품·경쟁사 발표로 바꾸지 않는다.

## 직접 코드·보안 검토

새 의존성·수집 엔드포인트·주문·AI 호출·자격증명 경로·DB 마이그레이션이 없다.
동기 상세 조회는 로컬 편집 자료를 병합한다. 정확한 발행인별 좌표를 유지하고
다른 회사/연도/통화/값/원문의 중복 제거 금지와 기존 캐시 정규화를 검증했다.
출처는 HTTPS 검증과 화면 escape를 통과하는 구조를 유지한다. 관계 식별자를
대조해 Flowco(FLOC)와 ProFrac을 혼동하지 않도록 회귀 검증을 추가했다.
화면 캐시 버전을 갱신해 이미 배포된 목록 스타일 변경을 실제 브라우저에 적용한다.

CodeRabbit을 사용하지 않았다. 호스트 권한 disabled인 세션에서 변경 범위를
직접 검토한 기록이며 전체 Codex Security Scan 또는 OCI/KMS 게이트 통과가 아니다.

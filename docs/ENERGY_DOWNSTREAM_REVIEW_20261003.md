## 발견한 문제와 수정

- 기존 MPC·PSX·DINO 정유 모듈을 별도로 보존하고, 이번 17곳은 downstream
  모듈로 분리했다. 이전 정유 3곳의 실제 응답과 검사를 함께 확인했다.
- NGL의 부문 이름·전체 차원을 실제 원본과 맞췄다. 임의 축·다른 CIK·문서·
  기간에는 검토한 좌표나 음수 예외를 적용하지 않는다.
- 현재 연차 파싱이 이전 연도 일부 제품으로 되돌아가는 GPRE 문제를 수정했다.
  문서의 실제 연간 결산일을 따르고 잘못된/미래 기간은 거절한다. 기존 캐시의
  같은 문서·2024년 계약 제품 2개만 제외하며 다른 문서·기업·기간은 유지한다.
- SPH 고객 유형은 기존 파싱 그룹 열거에 없어 누락됐다. end_market을 포함했다.
- SGU의 실제 연간 현금 항목을 추가했다. REX의 음수는 해당 원문·태그·기간·
  파생상품 좌표에 한정하고 일반 제품 음수 허용으로 확대하지 않았다.
- JetBlue 등록 ID와 종목 연결 누락으로 그래프 등록 검사가 실패했다. 공식
  발표의 Nasdaq JBLU를 등록하고 기존 공개 프로필과 같은 기업 ID를 사용한다.
- 실제 HTTP 검사에서 매출 표가 빈 배열로 나왔다. 원문 보관소에만 있던 104행을
  기업 편집 병합 경로에도 연결했다. 비어 있는 기존 캐시 응답의 회귀 검사를 추가했다.
- HTTP 상대 확인은 JETBLUE AIRWAYS 대문자를 처리하지 못했다. 검사 문자열을
  대소문자 무관하게 고쳤으며 앱의 기업명을 임의 변경하지 않았다.

초기 집중 검사 2회(등록 누락·검사 필드명), 잘못된 discover 옵션 1회와 초기
HTTP 2회 실패는 성공으로 계산하지 않는다. 테스트는 실제 앱 조회를 대체하지 않는다.

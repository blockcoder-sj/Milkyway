# 개인용 시장 화면

## 구현 마일스톤

- **M5.1 수집·저장 완료**: 고정된 37개 지표, 전용 `market-data` 프로세스,
  1분 주기 수집, 45초 전체 제한, 원자적 캐시 교체, 부분 실패 시 이전 값 보존.
  직접 코드 검토와 합성 응답 기반 검사 11개 통과. 증권사 키와 AI API를 사용하지 않습니다.
- **M5.2 화면 완료**: 한국·미국 선택, 지수·환율·선물 카드, 섹터 등락 정렬,
  지표별 세부 설명·기준값·범위·출처·시간·장중 차트.
- **M5.3 로컬 적용·검증**: 호스트 회귀 검사 297개 통과, 공개 데이터 37개
  수신 이력 확인, Docker 6개 서비스 실행 및 Chrome에서 한국·미국 지수,
  미국 11개 섹터·한국 8개 업종, 하락률 정렬과 세부 정보 확인.

2026-09-30 확인입니다. 공급자 오류 시 이전 값을 유지하고 지연 상태를 표시하는
실제 동작도 확인했습니다. 장시간 무중단 수신이나 실제 증권사 인증·체결 성공을
의미하지 않습니다. 이번 작업에서 AI API는 호출하지 않았습니다.

기존 CI의 의존성 검사에서 PyJWT 2.13.0 취약점 10건이 발견되어 2.14.0으로
업데이트했습니다. 공식 PyPI wheel 해시를 고정하고 재검사한 런타임 의존성
65개에서 알려진 취약점 0건을 확인했습니다. 전체 저장소 심층 보안 감사와는
별도 검사입니다. JWT 정상 처리·빈 대칭 JWK 거부 회귀 검사를 추가했습니다.

## 제공 범위

| 구분 | 항목 |
|---|---|
| 미국 주요 지수 | S&P 500, 다우, 나스닥 종합, 나스닥 100, 러셀 2000, VIX |
| 한국 주요 지수 | 코스피, 코스닥, 코스피 200 |
| 환율 | 원/달러, 원/100엔, 원/유로, 엔/달러, 달러/유로 |
| 선물·원자재 | E-mini S&P 500, E-mini Nasdaq 100, 금, WTI 최근월 선물 |
| 미국 섹터 | S&P 500의 GICS 11개 섹터 지수 |
| 한국 업종 | 코스피 전기·전자, 화학, 운송장비, 운수·창고, 건설, 금융업, 증권, 보험 지수 |

한국은 주요 8개 업종이며 전체 업종을 포괄하지 않습니다. 금융업과 증권·보험은
구성 범위가 겹칩니다. 미국 섹터 값은 ETF 가격이나 자체 동일가중 평균이 아닌
공급자가 제공한 S&P 500 섹터 지수입니다.

## 데이터 의미

- 시장 화면은 Yahoo Finance의 개인용 공개 참고 데이터를 사용합니다. 증권사
  연결이나 페이퍼 계좌 생성 전에도 수집합니다. 출처 페이지를 각 카드에서 엽니다.
- 시세 기준 시각과 PC의 수집 시각을 구분합니다. 1분 수집 주기는 무지연 시세를
  뜻하지 않습니다. 장중에는 `지연 가능`, 장외에는 `최근 종가`, 실패하거나
  오래된 값에는 `갱신 지연`을 표시합니다.
- 전일 대비는 공급자의 `previousClose`와 지표값의 차이입니다. 전일 기준값이
  없으면 등락률도 `—`로 표시합니다. 원/100엔은 가격·전일값·차트를 모두 100배 합니다.
- 선물은 최근월 계약이며 만기 교체 영향을 받을 수 있습니다. 환율은 참고용으로,
  증권사의 실제 환전 적용 환율과 다를 수 있습니다.
- 원본 응답을 검증한 값만 표시합니다. 실패한 지표는 마지막 성공 값을 기준 시각과
  함께 유지하며, 성공 이력이 없으면 수신 실패/대기로 표시합니다.
- `내 전략 종목 · 증권사 시세`는 별도 영역입니다. 시장 참고 데이터는 `Quote`,
  `MemberQuote`, 주문·체결 원장, 전략 데이터셋에 기록하지 않습니다.

## 구조와 실행

- `market_catalog.py`: 표시 항목과 설명
- `market_feed.py`: 고정 공급자 요청, 크기·시간·심볼·자산 유형·수치 검증
- `market_service.py`: 캐시 보존·읽기 및 시간에 따른 상태 계산
- `market_worker.py`: 개인 설치 전용 수집 스케줄과 상태 신호
- `static/market.js`: 출처와 수치 표시만 담당. API 호출이나 매매 동작 없음

`docker compose -f compose.personal.yaml up -d --build`로 갱신합니다.
`market-data`가 실행되는지 확인합니다. 최초 수집에는 최대 약 45초가 걸릴 수 있습니다.
공급자 오류가 나면 다음 주기에 다시 수집하며 체결 프로세스에는 영향을 주지 않습니다.

참고: [Yahoo S&P 500 지수](https://finance.yahoo.com/quote/%5EGSPC/),
[Yahoo S&P 500 정보기술 지수](https://finance.yahoo.com/quote/%5ESP500-45/),
[S&P 섹터 지수 설명](https://www.spglobal.com/spdji/en/index-family/equity/us-equity/sp-sectors/),

미국 11개 섹터 전체를 제공하는 경로로 사용하지 않습니다.

## 증권사 우선 조회 (2026-09-30)

개인용 설정에서 검증하여 저장한 증권사 연결을 사용한다. 환경 변수에 키만
입력한 상태는 연결 완료가 아니다. 지원하지 않는 항목·미수신·만료·연결 해제는
Yahoo 캐시로 보완하며, 값과 기준 시각·출처·대체 사유를 함께 표시한다.

| 연결 | 우선 사용 항목 | 수신 방식 |
| --- | --- | --- |
| 한국투자증권 실전 시세 키 | 코스피·코스닥·코스피200, 표시 중인 국내 8개 업종 | H0UPCNT0 WebSocket, 화면 2초 갱신 |
| 한국투자증권 모의 환경 | 이 시장 지표 연결은 미사용 | Yahoo 보완; 실전 환경으로 키를 임의 전환하지 않음 |
| 토스증권 | 코스피·코스닥 | 현재값 REST 15초 조회; 스트리밍으로 표시하지 않음 |
| 토스증권 | 원/달러 | 1분 단위 매매기준율(midRate), validUntil 이후 미사용 |
| 공통 | 미국 지수·미국 섹터·나머지 환율·선물 | Yahoo 1분 수집 |

토스 지표 응답에 전일 종가가 없으므로 등락률을 임의 계산하지 않는다.
증권사 현재값과 Yahoo 전일 기준값·차트를 섞지 않는다. KIS는 30초 이내의
수신만 실시간으로 표시하며, 장 종료 후 무수신이면 Yahoo 최근 종가로 전환한다.
Yahoo 수집은 별도의 실행 스레드와 제한 시간 45초의 하위 프로세스에서 실행되어
KIS 수신을 막지 않는다. 공급자 장애 재연결에는 60초 대기 시간을 적용한다.

### 검토 기록

- 합성 응답으로 시장 관련 27개 테스트 통과. 전체 회귀 312개 통과
  (2026-09-30, host Python 3.12). AI API와 실제 증권사 키는 사용하지 않았다.
- 최대 400점 × 37지표 캐시 읽기·검증·JSON 직렬화 500회: 중앙값 5.68ms,
  p95 7.08ms. 초기 모듈 로딩을 포함한 최대값 255.55ms. 응답 약 130KB.
  실제 네트워크 지연·증권사 처리량을 측정한 결과는 아니다.
- 직접 코드·보안 검토: 고정 API 주소/구독, 리다이렉트·환경 프록시 차단,
  응답·프레임 크기 제한, 프로세스 제한 시간, 소유자·자격증명 변경별 캐시 분리,
  원문 오류/키 비노출, 실전 주문 및 페이퍼 원장 쓰기 경로 없음을 확인했다.
- KIS 공식 WebSocket 주소는 TLS 없는 `ws`다. 이 경로에는 시세 구독 승인 키만
  보내고 App Key/Secret은 HTTPS 인증에만 사용한다. 수신 데이터는 참고 화면
  전용이며 페이퍼 체결에 사용하지 않는다. 실제 키로 수신 성공 여부는 별도다.

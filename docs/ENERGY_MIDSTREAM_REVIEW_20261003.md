# Energy 가스·NGL·LNG 중간 검토

기준: 2026-10-03 KST. 이 마일스톤은 섹터 완료가 아니다.

## 반영

- WMB/KMI/TRGP/OKE/LNG의 사업·제품·고객·원료·시설·계약·운영 요인을 한국어로 편집했다.
- 실제 가스 구매·LNG 판매·운송 고객·EPC·배관 공동사업·자산 운영 관계를 추가했다.
- 운영 상대 15곳의 역할 자료와 역방향 탐색 링크를 연결했다. 비상장 상대 전체의 매출을 단일 계약으로 추정하지 않았다.
- Williams Momentum 인수는 2026-09-03 완료, Cheniere Stage 3는 2026-08-28 마지막 설비 인계로 갱신했다. Petrobras의 2026-09-29 계약도 추가했다. 발표에 없는 개시 연도는 만들지 않았다.
- Western Gateway의 FID·지분·건설 목표를 반영했다. 현재 가동망과 구별했다.
- 사업 설명과 실제 공시 매출 표를 연결했으며, 소계·세부 항목과 계약 고객 매출·회사 총매출을 구별했다.

## 수치 검토

- KMI 외부 부문 매출 합계: 16,937,000,000 USD. 지리 매출 합계도 동일하다.
- OKE 두 소계가 다섯 세부 항목과 각각 일치하며 최상위 합계는 33,629,000,000 USD다.
- LNG 고객 계약 매출 세 항목 합계: 19,464,000,000 USD. 외부 조달 LNG 226,000,000 USD는 LNG 판매에 포함된다. 파생상품·임대 등 포함 총매출 19,976,000,000 USD와 다르다.
- WMB 계약 고객 매출 14,899,000,000 USD와 연결 총매출 11,950,000,000 USD는 범위가 다르다. 같은 매출 지표 총액 기준으로만 비중을 표시한다.
- TRGP 두 부문의 외부 매출은 기타 조정 −5,300,000 USD를 포함해야 연결 17,028,300,000 USD와 일치한다. 이 표의 비중을 생략하고 사유를 표시한다. 내부거래·제거 좌표는 수신하지 않는다.

## 기능·직접 검토·보안

- 관련 오프라인 검증 54개 통과(0.764초). 전체 539개 통과(54.552초, Docker에 Node가 없어 17개 건너뜀).
- 호스트 Node 화면 검증 9개 통과(6.141초). 새 조정 안내의 HTML 이스케이프와 비중 제외도 확인했다.
- 전체 검증 첫 시도는 임시 테스트 경로의 쓰기·실행 제한 때문에 6개 실패했다. 별도 컨테이너의 임시 runtime·실행 가능한 tmp를 제공하고 전부 재검증했다. 사용자 runtime·키·백업을 테스트에 마운트하지 않았다.
- 직접 소스 검토: 기업·CIK·공시 기간·정확한 차원 좌표, 기존 관계 보존, 데이터 모델 한도, 두 번 적용해도 동일한 결과, 원래 입력 불변을 확인했다.
- 새 문구는 서버에서 400자 제한, 화면에서 이스케이프한다. 외부 호출·실행 코드·호스트 허용 목록·키 접근은 추가하지 않았다. 실제 AI 제공사 호출 0회다. CodeRabbit을 사용하지 않았다.
- 전체 보안 스캔 및 공개 OCI 배포 게이트 완료를 주장하지 않는다. 개인 로컬 범위의 변경 검토다.

## 이어서 진행하는 조사

- 내려받은 원문은 185개 대상 종목의 345개 연차·분기 문서다. 복수 종목이 같은 운영 자산이나 법인에 연결될 수 있다. 다운로드 건수는 편집·거래·최신 변경 검수 완료 기업 수가 아니다.
- 기존 CVX/COP/VLO/MPC/PSX/DINO와 이번 5곳을 합쳐 11개 주 대상의 심화 자료를 확장했다. 11곳 모두 전 항목 완료로 세지 않는다.
- EPD/ET/MPLX/PAA/PAGP/WES/HESM 등 MLP·운영 기업, 나머지 탐사·생산·장비·시추·운송·연료·로열티 기업 조사와 기존 자료 후속 검수가 남아 있다.
- 무료 공식 구성 목록과 회사의 사업 탐색 분류를 구별한다. NFG는 공식 운용사 분류상 Utilities다. NRGU/RISE 같은 금융상품과 USDP 같은 운영 중단 법인은 사업 회사 목록에서 분리해야 한다.

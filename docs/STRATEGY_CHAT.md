# 대화와 직접 조정을 통한 전략 개발

가설만 입력해 새 대화를 시작할 수 있다. 각 요청은 전송 내용을 확인하고
**1회 유료 호출 승인**을 눌러야 실행된다. 단순 화면 갱신·설정 조정은 AI를 호출하지 않는다.

저장한 전략에서 초기 자금, 전체 투자 비중, 종목당 상한, 최대 보유 수,
리밸런싱 간격·방식, 손절, 비용, 필터와 신호의 관찰 기간·가중치를 바꿀 수 있다.
변경은 별도 전략 버전으로 저장한다. 기존 버전과 운용 중 계좌는 유지된다.
승인 대기 중에는 기준 전략을 변경할 수 없으며, 저장되지 않은 조정을 남긴
상태로 대화 기준을 바꾸려 하면 안내한다.

비중은 리밸런싱 직전 평가액을 기준으로 한다. 비용을 지불할 현금을 확보한
뒤 매수하므로 실제 비중은 목표보다 낮아질 수 있다. 잔여 현금은 유지한다.
‘종목만 교체’ 모드는 기존 수량을 그대로 두므로 보유 중 비중 상한을 다시
맞추지 않는다. ‘동일 비중 재조정’은 일부 매도와 추가 매수를 지원한다.
과거 백테스트와 페이퍼가 동일한 순수 배분 함수를 사용한다.

현재 실행 범위는 미국 주식 일봉의 6종 신호 순위 조합이다. 임의 Python,
장중 지표, 뉴스 조건, Boolean 임계값 등은 대화할 수 있지만 실행 지원으로
간주하지 않는다. 응답 지침은 이를 몰래 근사하지 말고 제한을 설명하도록 한다.

## 검토 기록 (2026-09-30)

- 새 버전의 불변성·중복 요청·타 소유자·승인 대기·오래된 기준 버전·숫자 범위 검증.
- 배분 함수 500개 합성 사례의 현금/수량/비용 보존, 정수 주식, 부분 매도,
  잔여 현금, 백테스트/페이퍼 통합 회귀 확인.
- 20종목 배분 10,000회: 중앙값 0.050ms, p95 0.054ms (host Python 3.12).
- 직접 코드·보안 검토: 조정 API의 소유자 검사, CSRF 의존성, 로컬 범위,
  quota 트랜잭션, 일회성 AI 승인, 출력 escaping, JSON만 해석하는 경계를 확인.
- 전체 회귀 324개 통과. 실제 AI 대화 평가는 별도로 기록한다.

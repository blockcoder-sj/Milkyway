# 기업 정보 정리·관계망 보강 — 2026-10-01

## 요청과 원칙

- 섹터 기업 목록을 종목별로 대조하고 분류 근거·확인 범위를 표시한다.
- 공식 공시·IR·공급망 목록·상대 기업 발표와 공개 조사 자료를 사용한다.
- Wikipedia/Wikidata의 설명·제품·관계·출처는 기존 자료에서도 제거한다.
  기존 공통 ID와 식별 별칭은 링크 이동을 위해 유지하며 백과 수집은 중단한다.
- 관계는 제품·역할·기준일과 함께 표시한다. 익명 고객·간접 공급망을 직접 거래로 만들지 않는다.
- 기업 기본 정리는 사업·매출 원천·제품·고객·공급망·경쟁과 관련 요인의 핵심을 먼저 표시한다.
  긴 원문은 접고 출처 링크는 하단에 모은다. 원문과 요약·번역을 구분한다.
- 무료 자료만 사용한다. AI provider 호출은 건별 사용자 승인 전 실행하지 않는다.
- 개인 거래·연구 DB와 Docker runtime/backup 볼륨은 보존한다.

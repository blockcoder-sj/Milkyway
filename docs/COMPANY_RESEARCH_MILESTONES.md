# 기업 정보 정리·관계망 보강 — 2026-10-01

## 요청과 원칙

- 섹터 기업 목록을 종목별로 대조하고 분류 근거·확인 범위를 표시한다.
- 공식 공시·IR·공급망 목록·상대 기업 발표와 공개 조사 자료를 사용한다.
- Wikipedia/Wikidata의 설명·제품·관계·출처는 기존 자료에서도 제거한다.
  기존 공통 ID와 식별 별칭은 링크 이동을 위해 유지하며 백과 수집은 중단한다.
- 관계는 제품·역할·기준일과 함께 표시한다. 익명 고객·간접 공급망을 직접 거래로 만들지 않는다.
- 기업 기본 정리는 사업·매출 원천·제품·고객·공급망·경쟁과 관련 요인의 핵심을 먼저 표시한다.
  긴 원문은 접고 출처 링크는 하단에 모은다. 원문과 요약·번역을 구분한다.
- 무료 자료만 사용한다. AI provider 호출은 건별 사용자 승인 전 실행하지 않는다.
- 개인 거래·연구 DB와 Docker runtime/backup 볼륨은 보존한다.

## 추가 요청 — 2026-10-02

사용자는 무료 자료를 더 폭넓게 사용해 업계를 이해할 수 있는 관계도와 가공된 정보를
요청했고 AI 전략 응답의 신뢰성 개선도 요구했다. M4/M5로 이어간다. 모든 수천 기업의
모든 공개·비공개 관계를 완전하게 확보하거나 외부 API 장애를 없앴다고 주장하지 않는다.
자료가 없으면 범위를 표시하고, 검증을 통과하지 못한 AI 결과는 전략 실행으로 전달하지
않는다. 실제 AI 테스트에 대한 새 승인 전 유료 호출을 실행하지 않는다.

## M5 실제 검수

응답이 중단됐을 때 완결된 대화만 복구하며 잘못된 전략은 저장·실행하지 않는다.
저장 실패도 대화·사용량을 보존하고 다시 입력하는 기능은 별도 승인으로 이어진다.
실행 규칙은 저장된 전략 규격에서 표시한다. 전체 회귀 459개, 호스트 화면 검사
14개, 네트워크 차단 프로세스 8단계 통과. Docker 패키지는 최초 전체 예산 초과 후
수집 일시 정지 재검사에서 동일 조건 7단계 통과했다. 새 유료 호출은 0회이며 새
최대 5회 검증 승인은 답변 대기 중이다. 자세한 제한·성능·보안 검토는
[AI 응답 검수](AI_RESPONSE_REVIEW_20261002.md)에 기록했다.

## 전체 원문 재무표 복구

182개 연차 원문을 대조해 173개 기업의 1,344개 보고값을 확보했다.
원문과 XBRL context의 CIK, 화폐 단위, 연차 기간, 차원 유무를 검증하며
연결 무차원 값만 사용한다. 순손실·음수 현금흐름은 부호를 보존한다.
부채가 없으면 자산−자본으로 만들어 넣지 않는다. 재무 API 실패 시에도
이미 수신한 공시를 재사용하므로 이 복구 과정의 추가 외부 호출은 없다.

XOM의 옛 operating issuer/새 holdco, HOS의 2025 Helix/2026 결합 그룹,
NINE의 predecessor/successor 회계와 ACDC의 68.8m 중간자본을 재무표
옆에 설명한다. ACDC 항목은 redeemable preferred stock이며 비지배지분이 아니다.
PBA/SOBO/TRP/GFR의 40-F 첨부 재무와 APC/CRT/NRT/PBT/SBR의 원문 표
검토가 남는다. 미지원 원문은 가짜 수치를 채우지 않는다.

## 직접 코드·보안 검토

새 외부 네트워크 경로·의존성·주문·자격증명 경로·DB migration은 없다.
매출의 정확한 발행인/축 조합만 허용하고 추가 축·다른 발행인을 거절한다.
검토한 문서·기간의 조정만 사용하며 과거 캐시의 표도 같은 규칙으로 정규화한다.
재무 영수증은 크기·행 수·원문 URL·태그·통화·기간·timezone을 제한한다.
원문 좌표만 같은 기존 값을 교체하며 다른 문서·기간 값은 보존한다.
financial_context도 백과 출처 거절·HTML escape·하단 출처 번호 정책을 따른다.
실제 화면에서 발견한 평행 기업명/법인 형태 행의 혼동을 수정했다. 기존
관할·법인 형태 phantom 관계는 제외하며 회사명으로 추정한 관할 설명을
지운다. 동일 issuer/tag/통화/기간/공시일/값인 companyfacts 재무 중복만
제외하고 해당 API 출처는 하단에 보존한다. 상이한 값·보고일은 유지한다.
이는 변경 범위 직접 검토이며 전체 Codex Security Scan/OCI/KMS 검수 주장이 아니다.

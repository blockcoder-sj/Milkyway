# Energy MLP 운영 자료 검토

기준: 2026-10-03. 섹터 완료가 아닌 이어지는 조사 마일스톤이다.

## 반영·수치 검수

- EPD/ET/MPLX/PAA/PAGP/WES/HESM의 제품·수익·자산·고객·투입 요소·경쟁 범위·최근 변화를 한국어로 편집했다. 거래 상대 7곳의 역할과 역방향 링크를 추가했다. 모회사·별도 상장 법인·자회사·운영 자산을 구별한다.
- EPD 내부거래 제거 후 외부 부문 4개 합계 52,596,000,000 USD. 내부거래 포함 부문 총계 184,136,000,000 USD를 외부 매출로 표시하지 않는다.
- ET의 정확한 3차원 외부 고객 좌표만 수신한다. 8개 외부 부문 합계 85,536,000,000 USD. 내부 고객·제거·추가 차원·다른 법인 좌표를 허용하지 않는다.
- MPLX 고객 계약 부문 2개 합계 9,726,000,000 USD. 임대·지분법·투자 손익 등 포함 12,998,000,000 USD와 구별한다. MPC 고객 비중은 공시의 주요 비현금 항목 제외 범위도 표시한다.
- PAA와 PAGP의 계속사업 제품+서비스 합계는 각각 44,262,000,000 USD다. 같은 물류 자산의 연결 매출을 산업 합계에 중복 더하지 않는다. 캐나다 NGL은 중단사업이다.
- WES 고객 매출 3,841,599,000 USD와 기타 포함 3,843,403,000 USD. Aris가 연초 편입됐다고 가정한 pro forma 4,281,744,000 USD는 실제 매출이 아니다.
- HESM 고객 계약 1,617,200,000 USD와 부문 매출 1,621,300,000 USD를 구별한다. Chevron 계약 95%에는 Chevron이 계약한 제3자 물량도 포함된다.

## 운영·관계의 기준 시점

- PAA Canadian NGL 매각은 2026-05-12 완료. USD·CAD 대가와 현금·운전자본·후속 조정 범위를 표시한다. Keyera는 자산 거래 상대이며 기존 JV나 현재 상품 공급 계약으로 만들지 않는다.
- ET Lake Charles의 기존 수입·재기화와 2025-12 중단한 수출 개발을 구분한다. 직접 고객 Entergy와 하류 전력 수요 Meta를 구별하고 CloudBurst FID 조건을 유지한다.
- HESM GIP는 2025-05-30 전부 매각, Chevron 후원사 변경은 2025-07-18. Targa LM4는 실제 처리료·전력비와 공동사업 두 역할이다.
- WES Brazos 인수 완료·JIP 2 실증 가동·미래 배관/공장 건설을 구분한다. 최근 분기에서 확인한 설명은 연차보고서 대신 분기·운영 발표를 출처로 표시한다.

## 검증·직접 코드·보안 검토

- 관련 58개 테스트 통과(1.051초). 첫 실행 1개 실패는 PAGP의 의미상 같은 문구를 테스트가 ‘중복’이라는 단어로 찾은 경우였으며 사용자 문구를 명확히 하고 재검증했다.
- 새 규칙은 기업·CIK·정확한 차원 세트에 한정된다. 일반적인 임의 다차원 허용 규칙은 추가하지 않았다. 원본 입력 불변·두 번 병합해도 동일한 결과·출처·모델 한도를 검증했다.
- 외부 HTTP·AI 호출·새 의존성·키 읽기·실행 코드·수집 동시성은 추가하지 않았다. HTTPS 출처와 기존 화면 이스케이프를 유지한다. CodeRabbit을 사용하지 않았다.
- 현재 18개 주 대상에 심화 자료가 있으나 전 항목 완료 기업 수로 표시하지 않는다. 남은 전체 기업의 사업·관계·최신 변경과 원문 외 공개 자료 조사를 계속한다.

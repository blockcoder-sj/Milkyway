# AI 대화 실제 평가 — 2026-09-30

사용자가 허용한 5회 안에서 앱의 미리보기·일회 승인 화면을 사용했다.
모델은 `gpt-5.4-mini`, 추론 `none`, 자동 재시도 0회, 출력 한도 4,000토큰이다.
평가용 하네스는 추가하지 않았다. 기존 HTTP/계약 회귀는 합성 응답만 사용한다.

| 호출 | 요청 | 관측 결과 | 승인 후 소요 |
|---|---|---|---|
| 1 | 미국 대형 기술주 모멘텀이라는 막연한 가설 | 공급자 요청 실패; 응답 없음 | 3.19초 |
| 2 | 같은 가설, 필요한 질문부터 요청 | 종목·손절·주기 3개 질문, 실행 범위 설명 | 18.20초 |
| 3 | 종목·신호·비중을 구체적으로 지정 | 연결/검증 실패; 정확한 원인 미확인 | 91.51초 |
| 4 | 동일 규칙을 완전한 전략으로 요청 | 실행 규격 v1 저장 | 8.61초 |
| 5 | v1 비중 45%, 상한 20%, 주기 10일로 변경 | v2 저장, 실적 회피 미지원 설명·미포함 | 90.74초 |

3/5 요청이 완료됐다. 입력/출력 성공 사용량은 각각 5,649/2,065토큰이다.
실패 요청의 사용량은 확인되지 않아 총 비용을 확정하지 않았다. 마지막 2회는
엄격한 JSON Schema 출력 계약 적용 후 성공했으나 표본이 작아 안정성 보장은 아니다.

## 확인된 동작

- 막연한 가설 → 질문 → 실행 가능한 가격/거래량 전략 → 일부 필드 변경.
- v1/v2 저장 규격 대조: 종목, 팩터, 필터, 손절, 비용 그대로;
  투자 비중, 종목당 상한, 리밸런싱 주기만 요청대로 바뀜.
- 실적 발표 전후 2일 매수 회피는 코드에 넣지 않았고 대체 조건도 넣지 않음.
- 화면에서 45%→50% 직접 조정 후 v3 생성; 실제 AI 호출 총수는 여전히 5개.
- 계좌 자동 배포·실제 주문은 하지 않았으며 전략 성과는 미검증.

## 발견한 품질 문제와 수정

- 초기 요청 실패 뒤 안전한 오류 코드 표시와 JSON 요구를 명확히 했다.
- 세 번째 실패의 원인은 확정할 수 없다. 이후 구조화 출력 스키마를 API에
  전달해 형식 제약을 강화했다. 자동 재호출은 추가하지 않았다.
- 다섯 번째 답변이 손절을 ‘고점 대비’라고 잘못 설명했다. 실제 코드는
  평균 매입단가 기준이다. 지침에 기준을 명시하고 운용 설정 화면은 저장
  규격으로부터 손절·비중 설명을 직접 생성하도록 바꿨다.
- 내부 필드명 노출을 줄이도록 대화 지침을 보강했다.
- 직접 조정 후 이전 AI 설명에 예전 비중이 남던 문제를 새 버전의 결정적
  설명 생성으로 수정했다. 기존 불변 버전의 기록은 소급 수정하지 않는다.
- 승인 화면 글자 수에 스키마 등 요청 전체 JSON을 포함했다.
- 일봉은 최신인데 장전 분할/배당 확인 대기를 ‘일봉 실패’로 표시하던 문구를
  구분했다. 데이터/기업행사 검증 전 신규 체결 차단은 그대로 적용한다.

이 지침 수정 후 추가 실제 AI 호출은 하지 않았다. 가설 구체화·규격 생성에는
사용 가능성이 확인됐지만, 설명 정확성·지연·다양한 가설 처리까지 충분히
검증됐다고 판단하지 않는다. 임의 전략 지원이나 최적 수익률을 주장하지 않는다.

## 검토 범위

직접 소스 검토: 승인·요청 digest·소유권·CSRF·JSON 파싱 경계, 출력 escaping,
수정 버전 불변성, 손절과 공통 배분 엔진의 의미를 확인했다. 새 권한이나 AI
자동 호출 경로는 추가하지 않았다. 기존 전체 회귀와 경계 테스트로 검증한다.

# 우주 관계도 선택 확대·간격 수정

2026-10-04 사용자의 확대 화면 피드백에 따라 전체 섹터 지도와 기업별 지도를
수정했다. 기존의 모든 천체 겹침 방지 기준은 이 요청으로 대체한다.

## 변경한 동작

- 천체 클릭·검색·관계 선택은 선택한 천체와 우선순위가 높은 **직접 연결 최대
  8개**를 확대한다. 중심 천체도 크게 표시한다. 직접 연결이 적으면 확인된
  연결만 표시하며, 먼 단계의 요소로 개수를 채우지 않는다.
- 선택 화면의 확대 기준은 이 작은 주변 집합이다. 전체 노드 수에 맞추어
  축소하지 않는다. 전체 섹터 지도의 최초 진입은 전체 보기이며, 기업 지도는
  해당 기업 주변의 집중 보기로 시작한다.
- `전체 맞춤`으로 불러온 요소·연결 전체를 다시 표시한다. 집중 화면 밖의
  요소도 검색과 근거 목록에서 선택할 수 있다. 목록 페이지가 지도 자료를
  잘라내지 않는다.
- 전체 노드 수에 비례하던 직접 연결 반경과 XYZ 충돌 시 바깥으로 밀어내는
  처리를 없앴다. 투영 후 화면의 빈자리로 천체를 옮기던 처리도 제거했다.
  겹침을 허용하고 확대·회전이 실제 XYZ 위치에 따라 동작한다. 겹친 천체는
  클릭 지점에 가장 가까운 중심을 선택한다.
- 섹터 근거 목록도 지도와 같은 탐색 우선순위로 정렬한다. 공급·고객·소유·
  사업 관계, 출처 구분, 연결 단계에 따른 기존 순서를 사용한다. 중복 수신
  횟수로 점수를 올리지 않는다. 실제 거래액이나 경제적 영향력의 측정 순위는
  확보하지 않았으며 거리 설명에도 이를 명시한다.

## 검증·직접 검토

- 격리 컨테이너 전체 검사: **770개 / 23.659초 OK, skip 21**. Node 미설치로
  건너뛴 화면 검사는 호스트의 **24개 / 0.704초 OK**로 확인했다. 이후 기업
  안내 문구를 집중 보기로 맞추고 최종 지도·기업 화면 **8개 / 0.276초 OK**를
  다시 확인했다. 검사 실패나 새 의존성은 없다.
- 실제 저장된 **5,837개 요소 / 6,516개 연결**로 Energy·XOM·원유 가격 중심,
  3D/2D, 800×560/340×480의 **12개 배치**를 확인했다. 중심과 직접 연결 8개가
  모두 선택 화면 안에 놓인다. 이 주변 요소의 평균 XYZ 반경은 이전 배치보다
  최소 **84.2% 감소**했다. 전체 노드는 보존했다.
- Node 측정 최대 XYZ 조립 **31.573ms**, 9개 집중 투영 **0.072ms**.
  브라우저 프레임 속도를 뜻하지 않는다. 실제 Chrome의 안정된 집중 그리기
  관측은 섹터 **2.0–6.8ms**, 기업 **0.6–7.3ms**였다. 애니메이션·최초 전체
  그리기를 포함한 모든 프레임의 최대값이나 보장 수치는 아니다.
- 기존 Chrome 탭에서 XOM의 확대된 중심·주변 연결을 실제 화면으로 확인했다.
  Scorpio Tankers 천체를 클릭해 중심·근거 이동을 확인했고 원유 수급·가격의
  2D 집중 보기와 EIA 출처를 확인했다. `전체 맞춤`은 5,837개로 복귀한다.
- XOM 기업 지도는 46개 요소 / 48개 관계를 유지하면서 9개 천체를 집중 표시한다.
  SLB 선택은 확인된 직접 연결 1개와 중심만 표시하며 근거 패널도 SLB로 바뀐다.
  전체 보기 46개 복귀, 목록 2페이지에서 자료 유지, 가로 넘침 없음도 확인했다.
  이번에는 브라우저 화면 크기 강제 변경이나 실제 터치 검사를 하지 않았다.
- 변경 소스를 직접 검토했다. 외부 스크립트·새 네트워크 요청·AI 호출을
  추가하지 않았고, 출처 이스케이프·HTTPS 검증·인증 경계는 유지한다.
  검색·전체 복귀·2D 모드 유지·클릭 대상 선택·유휴/숨김 중단 회귀 검증을 확인했다.
